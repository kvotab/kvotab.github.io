Citation styles

SKB Harvard styles for Zotero

  • Download English style For reports written in English: p, pp, (ed), In, n d, Available at:.
  • Download Swedish style For reports written in Swedish, per chapter 6: s, (red), I, u å, Tillgänglig:.
Both styles implement SKBdoc 1215757. To install one: save the file, then in Zotero open Settings → Cite → Styles, press + and choose it. If Zotero warns that the style is not valid CSL, install it anyway: the warning is about the language-dependent layouts that add “(In Swedish.)”, an extension Zotero’s citation processor supports. In Word, pick the style in the Zotero tab under Document Preferences. Each file begins with a comment block explaining how to fill in the Zotero fields for SKB reports, SKBdoc documents, standards and laws, and which few cases still need a manual edit.

Zotero settings
Credentials are kept only in this page's memory and are not included in downloaded reports. References are formatted by the built-in SKB reference formatter. For security, prefer an API key over a username and password. A local Zotero database requires Zotero's local API to be enabled. Edge must also grant this site Local Network Access; use “Request/test local access” after selecting the local source.
Rule packs

Active rule sets

    The three official SKB guides are built in and always apply. A rule pack is a JSON file holding project-specific terminology and preferences, either a bare array of rules or { "name": …, "description": …, "rules": [ … ] }, where each rule is { "pattern": "\\bflux\\b", "description": "Use release", "enabled": true }. Packs are remembered in this browser and the document is re-analysed when one is added or removed.
