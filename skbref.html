Credentials are kept only in this page's memory and are not included in downloaded reports. References are formatted by the built-in SKB reference formatter. For security, prefer an API key over a username and password. A local Zotero database requires Zotero's local API to be enabled. Rule packs

Active rule sets

    The three official SKB guides are built in and always apply. A rule pack is a JSON file holding project-specific terminology and preferences, either a bare array of rules or { "name": …, "description": …, "rules": [ … ] }, where each rule is { "pattern": "\\bflux\\b", "description": "Use release", "enabled": true }. Packs are remembered in this browser and the document is re-analysed when one is added or removed.
