# kvotab.github.io

The source of [kvotab.se](https://kvotab.se): free, browser-based tools for
radiological safety assessment and a few things beside. Kvot AB's own code is
under the MIT licence ([LICENSE](LICENSE)); the libraries, fonts and data it
uses keep their own, listed in [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md).

One tool is a subtree of its own: [`kompartment/`](kompartment/) is the
compartment modelling editor, with its own guide, tests and licence notice. The
page [`kompartment.html`](kompartment.html) frames it in the site's chrome, and
`kompartment/` serves the same tool on its own.
