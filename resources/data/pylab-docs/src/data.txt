@ sum
The sum of the elements, down the columns by default.

Of a vector, the sum of its elements; of a matrix, a row of column sums. Give a dimension to sum along another way (2 for the rows), or `'all'` for one total. A `NaN` makes the sum `NaN` unless `'omitnan'` leaves it out.

S = sum(..., 'omitnan')

rowSums = sum(A, 2)

## Missing values

@ skewness, kurtosis
The sample skewness and kurtosis.

The skewness measures asymmetry: 0 for symmetric data, positive when the right tail is longer. The kurtosis measures how heavy the tails are: 3 for the normal distribution (not the excess over 3). With `flag` 0 the bias of a small sample is corrected; 1 (the default) gives the plain sample values.

# Syntax
s = skewness(X)
    The skewness of each column (or of a vector).
s = skewness(X, flag)
    With `flag` 0, corrected for bias.
k = kurtosis(X)
    The kurtosis.
k = kurtosis(X, flag)
    With `flag` 0, corrected for bias.
# Examples
## A symmetric sample and a skewed one
rng default
n = randn(1, 50000);
e = -log(rand(1, 50000));
round([skewness(n) skewness(e); kurtosis(n) kurtosis(e)], 2)

mean std moment

@ movmean, movsum, movprod, movmax, movmin, movmedian, movmad, movstd, movvar
Statistics over a moving window.

Each element of the result is the statistic of a window of `k` neighbouring elements around it (for an even `k`, one more before than after), or of `kb` before and `kf` after. Near the ends the window shrinks to the elements there are. Moving means smooth noisy data; a moving median does so without being pulled by outliers.

# Syntax
M = movmean(A, k)
    The mean of each window of `k` elements.
M = movmean(A, [kb kf])
    Of `kb` elements before and `kf` after.
M = movmean(..., dim)
    Along dimension `dim`.
M = movsum(A, k)
    The sum (and the same forms for `movprod`, `movmax`, `movmin`, `movmedian`, `movmad`, `movstd` and `movvar`).
# Examples
## Windows of three
x = [4 8 6 -1 -2 -3 -1 3 4 5];
movmean(x, 3)
movmax(x, [1 0])
## Smoothing noise, and an outlier
rng default
t = 1:100;
y = sin(t/10) + 0.2*randn(1, 100);
y(40) = 3;
plot(t, y, '.', t, movmean(y, 9), t, movmedian(y, 9))
legend('data', 'movmean', 'movmedian')

smoothdata filter conv

@ rescale
Scale values linearly to fill [0, 1], or another interval.

The smallest value goes to the lower end and the largest to the upper end, the others in proportion. `'InputMin'` and `'InputMax'` set the range taken as the input's, clamping what lies outside.

# Syntax
R = rescale(A)
    To [0, 1].
R = rescale(A, l, u)
    To [l, u].
R = rescale(..., 'InputMin', inmin, 'InputMax', inmax)
    With the input range given.
# Examples
## To [0, 1] and to [-1, 1]
rescale([2 4 6 10])
rescale([2 4 6 10], -1, 1)

@ normalize
Centre and scale data (z-scores by default).

By default each column has its mean subtracted and is divided by its standard deviation, so that the result has mean 0 and standard deviation 1. Other methods scale to a norm, to a range, or by the median and interquartile range; the extra outputs give the centre and scale used, to apply the same to other data.

# Syntax
N = normalize(A)
    Z-scores of each column (or of a vector).
N = normalize(A, dim)
    Along dimension `dim`.
N = normalize(..., 'range', [a b])
    Scaled to [a, b].
N = normalize(..., 'norm', p)
    Divided by the p-norm.
N = normalize(..., 'medianiqr')
    Centred on the median, scaled by the interquartile range.
[N, C, S] = normalize(...)
    With the centre and scale.
# Examples
## Z-scores, and their mean and spread
x = [2 4 4 4 5 5 7 9];
z = normalize(x)
[mean(z) std(z)]
## A range and a norm
normalize([2 4 6], 'range')
normalize([3 4], 'norm')

@ islocalmax, islocalmin
Where the local maxima (or minima) of data are.

A local maximum is higher than its neighbours on both sides; the first and last points never are. The prominence (the second output) says how far each stands out: the height above the higher of the lowest points between it and a higher peak on either side. `'MinProminence'` keeps the clear peaks only, and `'MinSeparation'` keeps peaks apart.

# Syntax
TF = islocalmax(A)
    True at the local maxima.
TF = islocalmax(A, dim)
    Along dimension `dim`.
[TF, P] = islocalmax(..., 'MinProminence', p, 'MinSeparation', d, 'MaxNumExtrema', n)
    With conditions, and the prominences.
TF = islocalmin(A)
    True at the local minima (and the same forms).
# Examples
## Peaks and valleys
x = [1 3 2 5 4 4 6 2];
find(islocalmax(x))
find(islocalmin(x))
## Only the clear peaks
t = linspace(0, 10, 500);
y = sin(t) + 0.1*sin(15*t);
tf = islocalmax(y, 'MinProminence', 0.5);
plot(t, y, t(tf), y(tf), 'o')

findpeaks max ischange

@ ischange
Where abrupt changes in data begin.

Splits the data into segments in which the mean (by default), the variance, or the slope and intercept of a line stay the same, and marks the first point of each new segment. `'Threshold'` sets how large a change must be (a cost for each change), and `'MaxNumChanges'` asks for the best split with at most that many.

# Syntax
TF = ischange(A)
    Changes in the mean.
TF = ischange(A, method)
    `'mean'`, `'variance'` or `'linear'`.
[TF, S1, S2] = ischange(A, method, dim, 'Threshold', t, 'MaxNumChanges', k)
    With conditions, and each segment's mean and variance (or slope and intercept).
# Examples
## Steps in a level
rng default
y = [ones(1, 30), 3*ones(1, 30), 2*ones(1, 30)] + 0.1*randn(1, 90);
tf = ischange(y);
find(tf)
## Each segment's mean
rng default
y = [ones(1, 30), 3*ones(1, 30), 2*ones(1, 30)] + 0.1*randn(1, 90);
[tf, s1] = ischange(y, 'MaxNumChanges', 2);
unique(round(s1, 1))

@ trenddecomp
Trends of data: long-term, seasonal and the remainder.

Splits a series into a long-term trend `LT`, seasonal trends `ST` (a column for each) and a remainder `R`, with `LT + sum(ST, 2) + R` equal to the data. By singular spectrum analysis (the default), or by STL with the period given.

# Syntax
[LT, ST, R] = trenddecomp(A)
    By singular spectrum analysis.
[LT, ST, R] = trenddecomp(A, 'ssa', lag)
    With a lag of your own.
[LT, ST, R] = trenddecomp(A, 'stl', period)
    By STL, with the period (or periods) of the seasons.
# Examples
## A rising series with a yearly cycle
rng default
t = (1:120)';
y = 0.05*t + sin(2*pi*t/12) + 0.2*randn(120, 1);
[LT, ST, R] = trenddecomp(y, 'stl', 12);
plot(t, y, t, LT, t, ST)
legend('data', 'long-term', 'seasonal')
max(abs(LT + sum(ST, 2) + R - y))

@ resize, paddata, trimdata
An array padded or cut to a size.

`resize` makes an array the given length (or size), padding with a fill value (0 by default) or cutting as needed; `paddata` only pads and `trimdata` only cuts. Padding and cutting happen at the end unless `'Side'` says `'leading'` or `'both'`; `'Pattern'` pads by repeating the edge, the array, or its reflection.

# Syntax
B = resize(A, m)
    `A` padded or cut to length `m` (or to the size `m`).
B = resize(A, m, 'Dimension', dim, 'Pattern', p, 'FillValue', v, 'Side', s)
    With options.
B = paddata(A, m, Name, Value)
    Padded only, with the same options.
B = trimdata(A, m, 'Side', s)
    Cut only.
# Examples
## Padding and cutting
v = [1 2 3 4];
resize(v, 6)
resize(v, 2)
paddata(v, 7, 'Pattern', 'edge')
trimdata(v, 2, 'Side', 'leading')

@ uniquetol, ismembertol
Distinct values and members of a set, values within a tolerance taken as one.

Floating-point results that should be equal often differ in their last digits; these compare with a tolerance relative to the largest value instead of exactly. `uniquetol` keeps one value of each group (its smallest), and `ismembertol` tests membership.

# Syntax
C = uniquetol(A)
    The distinct values, within 1e-6 relative to the largest.
C = uniquetol(A, tol)
    Within `tol`.
[C, IA, IC] = uniquetol(...)
    With `C = A(IA)` and `A` about `C(IC)`.
LIA = ismembertol(A, B)
    True where a value of `A` is within the tolerance (1e-12 relative) of one of `B`.
[LIA, LocB] = ismembertol(A, B, tol)
    With a tolerance, and where they are in `B`.
# Examples
## Values that differ in their last digits
a = [0.1*3, 0.3, 0.2+0.1, 0.5];
unique(a)
uniquetol(a)
ismembertol(0.1*3, [0.3 0.6])

@ rmse, mape
The root-mean-square error and the mean absolute percentage error.

Measures of how far a forecast or a model `F` is from the actual values `A`: `rmse` is `sqrt(mean(abs(F - A).^2))`, in the units of the data, and `mape` is `100*mean(abs((A - F)./A))`, in percent. Down the columns by default.

# Syntax
E = rmse(F, A)
    The root-mean-square error.
E = rmse(F, A, 'all')
    Over every element.
E = rmse(F, A, dim)
    Along dimension `dim`.
E = mape(F, A)
    The mean absolute percentage error (and the same forms).
# Examples
## A forecast against the actual values
actual = [100 110 120 130];
forecast = [98 113 118 135];
rmse(forecast, actual)
mape(forecast, actual)
