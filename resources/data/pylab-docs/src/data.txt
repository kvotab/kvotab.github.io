@ sum
The sum of the elements, down the columns by default.

Of a vector, the sum of its elements; of a matrix, a row of column sums. Give a dimension to sum along another way (2 for the rows), or `'all'` for one total. A `NaN` makes the sum `NaN` unless `'omitnan'` leaves it out.

# Syntax
S = sum(A)
    The sums down the first dimension whose length is not 1.
S = sum(A, dim)
    The sums along dimension `dim`.
S = sum(A, 'all')
    The sum of every element.
S = sum(..., 'omitnan')
    With `NaN` values left out.
# Examples
## A vector, the columns and the rows of a matrix
sum([1 2 3 4])
A = [1 2 3; 4 5 6];
colSums = sum(A)
rowSums = sum(A, 2)
total = sum(A, 'all')
## Counting with logical values
> A comparison gives true (1) or false (0), so its sum counts the elements that pass.
x = [3 8 1 9 4 7];
nAbove5 = sum(x > 5)
## Missing values
v = [2 NaN 5];
sum(v)
sum(v, 'omitnan')
# See also
cumsum prod mean trapz

@ prod
The product of the elements, down the columns by default.

Of a vector, the product of its elements; of a matrix, a row of the column products. `prod(1:n)` is n factorial.

# Syntax
P = prod(A)
    The products down the first dimension whose length is not 1.
P = prod(A, dim)
    The products along dimension `dim`.
# Examples
## A factorial, and the products of columns and rows
prod(1:6)
A = [1 2; 3 4; 5 6];
prod(A)
prod(A, 2)
# See also
sum cumprod factorial

@ cumsum
Cumulative sums.

Each element of the result is the sum of the elements up to and including that point, down the columns by default. The last element of `cumsum(v)` is `sum(v)`.

# Syntax
B = cumsum(A)
    Running sums down the first dimension whose length is not 1.
B = cumsum(A, dim)
    Running sums along dimension `dim`.
B = cumsum(..., 'reverse')
    Running sums from the end back to the start.
# Examples
## Running totals
v = [1 2 3 4 5];
cumsum(v)
cumsum(v, 'reverse')
## A random walk
rng default
steps = sign(randn(1, 200));
plot(cumsum(steps))
xlabel('step')
ylabel('position')
# See also
sum cumprod diff

@ mean
The average.

The sum of the elements divided by their number, down the columns by default. A `NaN` makes the mean `NaN` unless `'omitnan'` leaves it out; `'Weights'` gives a weighted average.

# Syntax
M = mean(A)
    The averages down the first dimension whose length is not 1.
M = mean(A, dim)
    The averages along dimension `dim`.
M = mean(A, 'all')
    The average of every element.
M = mean(..., 'omitnan')
    With `NaN` values left out.
M = mean(..., 'Weights', w)
    A weighted average, `sum(w.*A)/sum(w)`.
# Examples
## Of a vector, and of the columns and rows of a matrix
mean([2 4 9])
A = [1 2 3; 4 5 6];
mean(A)
mean(A, 2)
## Leaving out missing values
x = [10 NaN 14 12];
mean(x)
mean(x, 'omitnan')
## A weighted average
grades = [5 4 3];
credits = [7.5 15 7.5];
mean(grades, 'Weights', credits)
# See also
median mode std sum

@ median
The middle value.

The value in the middle when the elements are sorted, or the average of the two middle ones when their number is even; down the columns by default. Unlike the mean, it is not pulled far by a few extreme values.

# Syntax
M = median(A)
    The medians down the first dimension whose length is not 1.
M = median(A, dim)
    The medians along dimension `dim`.
M = median(A, 'all')
    The median of every element.
M = median(..., 'omitnan')
    With `NaN` values left out.
# Examples
## Odd and even numbers of values
median([7 1 3])
median([7 1 3 10])
## Robust against an outlier
x = [2.1 2.3 2.2 2.4 95];
[mean(x) median(x)]
# See also
mean mode prctile

@ std, var
The standard deviation and the variance.

The variance is the average squared distance from the mean, normalized by N-1 (the unbiased estimate from a sample) unless `w` is 1, which normalizes by N. The standard deviation is its square root, in the units of the data. Both go down the columns by default.

# Syntax
s = std(A)
    The standard deviation, normalized by N-1.
s = std(A, w)
    With `w` 0 (N-1) or 1 (N), or a vector of weights.
s = std(A, w, dim)
    Along dimension `dim`.
v = var(A)
    The variance, normalized by N-1.
v = var(A, w, dim)
    With a normalization or weights, along dimension `dim`.
s = std(..., 'omitnan')
    With `NaN` values left out (and the same for `var`).
# Examples
## A sample's spread
x = [4 8 6 5 3 7];
s = std(x)
v = var(x)
s^2 - v
## N-1 and N
x = [1 2 3 4];
[std(x) std(x, 1)]
## Along the rows of a matrix
A = [1 3 5; 2 2 2];
std(A, 0, 2)
# See also
mean median mad

@ max, min
The largest or smallest elements, or the larger or smaller of two arrays element by element.

Of a vector, its largest (or smallest) element, and with a second output its position; of a matrix, a row of column maxima. With two arrays, the larger (smaller) of each pair of elements. `NaN` is left out unless every element is `NaN`.

# Syntax
m = max(A)
    The largest elements down the first dimension whose length is not 1.
[m, k] = max(A)
    With the index of the first largest element.
m = max(A, [], dim)
    Along dimension `dim`.
m = max(A, [], 'all')
    The largest of every element.
C = max(A, B)
    The larger of each pair of elements (a scalar `B` caps from below).
m = min(A)
    The smallest elements, and the same forms as `max`.
# Examples
## The largest value and where it is
v = [4 9 2 9 1];
[m, k] = max(v)
[lo, where] = min(v)
## Columns, rows and the whole matrix
A = [3 7 2; 8 1 5];
max(A)
max(A, [], 2)
min(A, [], 'all')
## Clipping values to a range
x = [-2 0.5 3 1.2];
clipped = min(max(x, 0), 1)
# See also
bounds sort cummax

@ sort
Sort the elements, down the columns by default.

Numbers sort in increasing order (`'descend'` for decreasing); `NaN` goes to the end. A second output gives the indices that put the elements in order, so other arrays can be sorted to match. Text sorts too: a cell array of character vectors or a string array.

# Syntax
B = sort(A)
    Each column (or a vector) in increasing order.
B = sort(A, dim)
    Along dimension `dim`.
B = sort(..., 'descend')
    In decreasing order.
[B, I] = sort(...)
    With the indices: `B` is `A(I)` for a vector.
# Examples
## Increasing, decreasing, and the order
v = [3 1 4 1 5 9 2 6];
sort(v)
[s, idx] = sort(v, 'descend')
## Sorting one array by another
names = {'Oslo', 'Rome', 'Kiruna'};
temps = [4 16 -12];
[~, order] = sort(temps);
coldestFirst = names(order)
## Text
sort({'pear', 'apple', 'fig'})
# See also
sortrows unique max issorted

@ unique
The distinct values, sorted (or in the order first met).

Each value appears once in the result. Extra outputs map between the two: `C = A(ia)` and `A = C(ic)`, so `ic` labels each element with its group, ready for counting with `accumarray`. Works for numbers, text in cell or string arrays, and rows with `'rows'`.

# Syntax
C = unique(A)
    The distinct values, sorted.
C = unique(A, 'stable')
    In the order they first appear.
C = unique(A, 'rows')
    The distinct rows of a matrix.
[C, ia, ic] = unique(...)
    With `C = A(ia)` and `A = C(ic)`.
# Examples
## Distinct values, sorted and as first met
v = [3 1 3 2 1 3];
unique(v)
unique(v, 'stable')
## Counting each value
v = [3 1 3 2 1 3];
[vals, ~, ic] = unique(v);
vals
counts = accumarray(ic(:), 1)'
## Distinct words
words = {'red', 'blue', 'red', 'green', 'blue'};
unique(words)
# See also
sort ismember accumarray histcounts

@ diff
Differences between neighbours, or the nth differences.

`diff(x)` is `[x(2)-x(1), x(3)-x(2), …]`, one element shorter than `x`. Divided by the spacing it approximates a derivative; `diff(x, 2)` takes differences twice. For a matrix it works down the columns.

# Syntax
D = diff(X)
    The first differences.
D = diff(X, n)
    The differences taken `n` times.
D = diff(X, n, dim)
    Along dimension `dim`.
# Examples
## Differences and second differences
x = [1 4 9 16 25];
diff(x)
diff(x, 2)
## A derivative by differences
h = 0.01;
t = 0:h:pi;
dydt = diff(sin(t)) / h;
maxError = max(abs(dydt - cos(t(1:end-1))))
## Where a signal changes
s = [0 0 1 1 1 0 1];
risesAt = find(diff(s) == 1) + 1

cumsum gradient

@ histcounts
Counts of values in bins.

Sorts the values into bins and counts each bin: the numbers a histogram draws, without drawing it. The bins are chosen from the data unless their number or their edges are given. A value equal to an inner edge falls in the bin to its right; the last bin includes its right edge.

# Syntax
[N, edges] = histcounts(X)
    Counts in bins chosen from the data, and the bins' edges.
[N, edges] = histcounts(X, nbins)
    In `nbins` bins of equal width.
[N, edges] = histcounts(X, edges)
    In bins with the given edges.
[N, edges, bin] = histcounts(...)
    With the bin each value fell in.
# Examples
## Counts in given bins
x = [1 2 2 3 3 3 4 7 8];
[N, edges] = histcounts(x, [0 2 4 6 8])
## Which bin each value fell in
[~, ~, bin] = histcounts([0.5 3.7 6.1], [0 2 4 6 8])
## Counts of a large sample
rng default
N = histcounts(randn(1, 1000), -3:3)
# See also
histogram discretize unique

@ any, all
Whether any element, or every element, is nonzero.

Down the columns by default, like `sum`; give a dimension or `'all'` for another way. `any` of an empty array is false and `all` of an empty array is true. They are the usual way to turn an array of comparisons into one condition for `if`.

# Syntax
tf = any(A)
    True for each column with at least one nonzero element.
tf = any(A, dim)
    Along dimension `dim`.
tf = any(A, 'all')
    True when any element at all is nonzero.
tf = all(A)
    True for each column whose elements are all nonzero (and the same forms as `any`).
# Examples
## Some, every and none
x = [3 -1 4];
any(x < 0)
all(x > 0)
any(x > 10)
## Columns and rows of a matrix
A = [1 0 1; 1 1 0];
all(A)
any(A, 2)
## One condition for an if
v = [0.2 0.5 0.9];
if all(v >= 0 & v <= 1)
    disp('every value is a probability')
end
# See also
find isempty if nnz

@ find
The indices of the nonzero elements.

Usually given a comparison: `find(x > 3)` gives the positions where it holds. The indices count down the columns (linear indices); with two outputs, rows and columns. `find(X, n)` stops after the first `n`.

# Syntax
k = find(X)
    The linear indices of the nonzero elements.
k = find(X, n)
    The first `n` of them.
k = find(X, n, 'last')
    The last `n` of them.
[row, col] = find(X)
    Their rows and columns.
[row, col, v] = find(X)
    With their values.
# Examples
## Where a condition holds
x = [5 0 8 0 3];
find(x)
find(x > 4)
find(x == 0, 1)
## Rows and columns in a matrix
A = magic(4);
[r, c] = find(A > 13)
## Replacing values found
y = [1 -2 3 -4];
y(find(y < 0)) = 0
# See also
any all nnz ismember

@ isequal
True when the arrays have the same size and values (NaN is never equal).

Compares whole arrays, not element by element: the sizes must agree and every value too. Numbers of different classes compare by value (`isequal(1, int8(1))` is true). Text, cells and structs compare their contents. `NaN` is not equal to itself; `isequaln` treats two `NaN`s as equal.

# Syntax
tf = isequal(A, B, ...)
    True when every argument equals the first.
# Examples
## Same values, different sizes
isequal([1 2 3], [1 2 3])
isequal([1 2 3], [1; 2; 3])
## Text and structs
isequal('abc', 'abc')
s1 = struct('a', 1, 'b', 'x');
s2 = struct('a', 1, 'b', 'x');
isequal(s1, s2)
## NaN
isequal(NaN, NaN)
isequaln(NaN, NaN)
# See also
isequaln eq strcmp
