@ fopen, fclose
A file opened for reading or writing, and closed.

`fopen` gives an identifier (3 or more; -1, with a message, when the file cannot be opened) for `fprintf`, `fgetl`, `fread` and the other low-level functions. The permission is `'r'` (read, the default), `'w'` (write, emptying the file), `'a'` (append), or with `'+'` both reading and writing; `'t'` or `'b'` asks for text or binary (the same here). `fclose` closes it (or every open file with `'all'`); files left open stay open until closed.

# Syntax
fid = fopen(filename, permission)
    Opened.
[fid, msg] = fopen(...)
    With a message when it fails.
fclose(fid)
    Closed.
fclose('all')
    All closed.
# Examples
## Written, appended, read
fid = fopen('log.txt', 'w');
fprintf(fid, 'first\n');
fclose(fid);
fid = fopen('log.txt', 'a');
fprintf(fid, 'second\n');
fclose(fid);
type log.txt
[fid, msg] = fopen('missing.txt')
# See also
fprintf fgetl fread

@ fgetl, fgets, feof, ferror, frewind, ftell, fseek
Lines read one at a time, and the position in a file.

`fgetl` reads the next line without its line break, `fgets` with it; both give -1 at the end. `feof` says whether the end is reached, `ferror` the last error's message. `ftell` gives the position in bytes from the start, `fseek` moves it (from `'bof'`, `'cof'` or `'eof'`, the start, here or the end), and `frewind` goes back to the start.

# Syntax
line = fgetl(fid)
    A line without its break.
line = fgets(fid)
    With it.
tf = feof(fid)
    At the end.
msg = ferror(fid)
    The last error.
p = ftell(fid)
    The position.
status = fseek(fid, offset, origin)
    Moved.
frewind(fid)
    Back to the start.
# Examples
## A file read line by line, then again
writelines(["one"; "two"; "three"], 'lines.txt');
fid = fopen('lines.txt');
while true
    s = fgetl(fid);
    if ~ischar(s), break, end
    fprintf('%s (%d)\n', s, numel(s));
end
feof(fid)
frewind(fid);
double(fgets(fid))
ftell(fid)
fseek(fid, -6, 'eof');
fgetl(fid)
fclose(fid);
# See also
fopen readlines textscan

@ fread, fwrite
Binary data read from a file and written to it.

`fwrite` writes the values of an array as bytes of a precision (`'uint8'` by default, or `'int16'`, `'double'`, `'float32'` and the like) and gives the count; `fread` reads them back, all of them or sizeA (a number, [m n] or [m Inf]), as doubles unless the precision says `'*int16'` (the same class) or `'int16=>single'`.

# Syntax
count = fwrite(fid, A, precision)
    Written.
A = fread(fid, sizeA, precision)
    Read.
[A, count] = fread(...)
    With the count.
# Examples
## Numbers as bytes
fid = fopen('data.bin', 'w');
fwrite(fid, [1 -2 300], 'int16');
fwrite(fid, pi, 'double');
fclose(fid);
d = dir('data.bin'); d.bytes
fid = fopen('data.bin');
a = fread(fid, 3, '*int16')'
b = fread(fid, 1, 'double')
fclose(fid);
# See also
fopen typecast

@ fscanf, textscan, textread
Formatted data read from files and text.

`fscanf` applies a format again and again to the file's text, gathering the numbers into a column (or sizeA). `textscan` reads columns: each conversion of the format is a column of the result, a cell array (numbers as numeric arrays, text as cells), with `'Delimiter'`, `'HeaderLines'`, `'CommentStyle'` and the like; it reads from a file or from text. `textread` is the older form, one output per field, from a file name.

# Syntax
A = fscanf(fid, format, sizeA)
    Numbers by a format.
C = textscan(fid, format, 'Delimiter', d, 'HeaderLines', n)
    Columns of a file.
C = textscan(text, format)
    Columns of text.
[a, b, ...] = textread(filename, format, 'headerlines', n)
    The older form.
# Examples
## A small table of mixed columns
writelines(["name,age,height"; "Ada,36,1.65"; "Alan,41,1.80"], 'people.csv');
fid = fopen('people.csv');
C = textscan(fid, '%s %d %f', 'Delimiter', ',', 'HeaderLines', 1);
fclose(fid);
C{1}'
C{2}'
class(C{2})
[names, ages] = textread('people.csv', '%s %d %*f', 'delimiter', ',', 'headerlines', 1);
ages'
## Numbers from text
fid = fopen('nums.txt', 'w'); fprintf(fid, '1 2 3\n4 5 6\n'); fclose(fid);
fid = fopen('nums.txt'); A = fscanf(fid, '%d', [3 Inf])'; fclose(fid);
A
D = textscan('x=1.5; y=2.5', '%*s %f', 'Delimiter', {'=', ';'});
D{1}'

sscanf readtable readmatrix

@ fileread, readlines, writelines
Whole text files read and written.

`fileread` gives a file's whole text as one character vector; `readlines` gives its lines as a string column (without line breaks); `writelines` writes strings to a file, one per line (`'WriteMode'` `'append'` to add to it).

# Syntax
text = fileread(filename)
    The whole text.
lines = readlines(filename)
    Its lines.
writelines(lines, filename)
    Written.
writelines(lines, filename, 'WriteMode', 'append')
    Added.
# Examples
## A list kept in a file
writelines(["milk"; "bread"], 'list.txt');
writelines("eggs", 'list.txt', 'WriteMode', 'append');
L = readlines('list.txt')
t = fileread('list.txt');
numel(t), sum(t == newline)

@ readmatrix, writematrix, readcell, writecell
Matrices and cell arrays read from delimited files and spreadsheets, and written.

`readmatrix` reads the numbers of a text file (or .xlsx spreadsheet), header lines detected or given, other cells NaN; `writematrix` writes a matrix comma-separated (or with `'Delimiter'`, or as a spreadsheet for .xlsx). `readcell` reads every cell, numbers and text, into a cell array, and `writecell` writes one.

# Syntax
A = readmatrix(filename, 'NumHeaderLines', n)
    Numbers.
writematrix(A, filename, 'Delimiter', delim)
    Written.
C = readcell(filename)
    Every cell.
writecell(C, filename)
    A cell array written.
# Examples
## Numbers, and numbers with text
writematrix(magic(3), 'm.csv');
type m.csv
readmatrix('m.csv')
writecell({'id', 'value'; 1, 2.5; 2, 'n/a'}, 'mixed.csv');
C = readcell('mixed.csv')
M = readmatrix('mixed.csv')

@ csvread, csvwrite, dlmread, dlmwrite
The older functions for numbers in delimited files.

`csvread` reads a comma-separated file of numbers, from a row and column offset (counting from 0); `dlmread` any delimiter. `csvwrite` and `dlmwrite` write them. `readmatrix` and `writematrix` are the newer forms.

# Syntax
M = csvread(filename, row, col)
    Comma-separated, from an offset.
M = dlmread(filename, delimiter, row, col)
    Any delimiter.
csvwrite(filename, M)
    Written with commas.
dlmwrite(filename, M, delimiter)
    With a delimiter.
# Examples
## Tabs and commas
dlmwrite('t.txt', [1 2; 3 4], '\t');
dlmread('t.txt', '\t')
csvwrite('c.csv', [5 6 7; 8 9 10]);
csvread('c.csv', 1, 1)

readmatrix writematrix
