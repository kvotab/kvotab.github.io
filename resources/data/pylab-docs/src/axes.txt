@ figure
Make a new figure window, or bring one to the front and make it current.

Plots go into the current figure, made when the first plot needs one. `figure` starts another, so that the next plot does not replace the last; `figure(n)` makes figure `n` current, making it if it does not exist. Name-value pairs set the figure's properties, such as `'Name'`, `'Color'` and `'Position'` (`[left bottom width height]` in pixels).

# Syntax
figure
    A new figure, which becomes the current one.
figure(n)
    Figure `n`, made if need be, as the current figure.
f = figure('Name', value, ...)
    A new figure with properties set, and its handle.
# Examples
## Two figures
x = linspace(0, 1, 50);
figure
plot(x, x.^2)
title('first')
figure
plot(x, sqrt(x))
title('second')
## A named figure of a chosen size
f = figure('Name', 'Results', 'Color', 'w', 'Position', [100 100 480 300]);
bar([3 5 2])
f.Name
# See also
gcf close clf subplot

@ subplot
Axes in a grid of tiles within the figure.

`subplot(m, n, p)` divides the figure into `m` rows and `n` columns of tiles and makes tile `p` current, counting along the rows. Plots then go into that tile. A vector of tile numbers spans several tiles. Calling it again with the same tile returns to those axes.

# Syntax
subplot(m, n, p)
    Tile `p` of an m-by-n grid.
subplot(m, n, [p1 p2])
    One axes spanning the tiles listed.
ax = subplot(...)
    With the axes' handle.
# Examples
## Four plots in a two-by-two grid
x = linspace(0, 2*pi, 100);
subplot(2, 2, 1)
plot(x, sin(x))
title('sin')
subplot(2, 2, 2)
plot(x, cos(x))
title('cos')
subplot(2, 2, 3)
plot(x, sin(2*x))
title('sin 2x')
subplot(2, 2, 4)
plot(x, cos(2*x))
title('cos 2x')
## A wide tile under two small ones
rng default
subplot(2, 2, 1)
histogram(randn(1, 500))
subplot(2, 2, 2)
scatter(rand(1, 30), rand(1, 30))
subplot(2, 2, [3 4])
plot(cumsum(randn(1, 200)))
# See also
tiledlayout nexttile figure axes

@ tiledlayout, nexttile
A grid of tiles for axes, filled one tile at a time.

`tiledlayout(m, n)` divides the figure into a grid; each `nexttile` makes the axes of the next tile current, along the rows. `nexttile(k)` goes to tile `k`. With `'flow'` the grid grows to fit however many tiles are asked for.

# Syntax
tiledlayout(m, n)
    An m-by-n grid of tiles.
tiledlayout('flow')
    A grid that rearranges itself as tiles are added.
nexttile
    The axes of the next tile.
nexttile(k)
    The axes of tile `k`.
ax = nexttile
    With the axes' handle.
# Examples
## Three tiles in a row
t = linspace(0, 1, 100);
tiledlayout(1, 3)
nexttile
plot(t, t)
title('linear')
nexttile
plot(t, t.^2)
title('square')
nexttile
plot(t, sqrt(t))
title('root')
## A flow layout
tiledlayout('flow')
for k = 1:5
    nexttile
    plot(sin(k*linspace(0, pi, 60)))
    title(sprintf('k = %d', k))
end
# See also
subplot figure

@ hold
Keep what is drawn when the next plot is added, or not.

By default each plot replaces what the axes show. After `hold on`, plots are added to the axes instead, each taking the next colour, until `hold off`. `hold` alone switches between the two.

# Syntax
hold on
    Add later plots to the current axes.
hold off
    Let the next plot replace what is there.
hold
    Switch between on and off.
# Examples
## Data, a fit and a marked point in one axes
rng default
x = linspace(0, 3, 30);
y = exp(-x) + 0.05*randn(size(x));
plot(x, y, 'o')
hold on
plot(x, exp(-x), 'LineWidth', 2)
plot(1, exp(-1), 'p', 'MarkerSize', 14, 'MarkerFaceColor', 'y')
hold off
legend('data', 'model', 'x = 1')
# See also
plot ishold figure cla

@ title
The title of the axes.

Text above the axes. A cell array gives several lines. As with labels and legends, `^{…}` and `_{…}` make superscripts and subscripts, and `\alpha` and the other Greek letters, `\pm`, `\circ` and `\infty` their symbols. Name-value pairs set `'FontSize'`, `'FontWeight'`, `'Color'` and the rest.

# Syntax
title(text)
    The axes' title.
title(text, 'Name', value)
    With text properties.
t = title(...)
    With the text object, to change later.
# Examples
## A title with symbols, and labels
x = linspace(0, 4*pi, 300);
plot(x, exp(-0.2*x).*sin(x))
title('Damped oscillation: e^{-0.2t} sin(\omega t), \omega = 1')
xlabel('t (s)')
ylabel('amplitude')
## Two lines, and a larger font
plot(rand(1, 10))
title({'Measurements', 'second series'}, 'FontSize', 14)
# See also
xlabel ylabel subtitle sgtitle text

@ xlabel, ylabel, zlabel
The labels of the x, y and z axes.

Text beside an axis, usually its quantity and unit. The same TeX symbols as in `title` work here.

# Syntax
xlabel(text)
    The label of the x axis.
ylabel(text)
    The label of the y axis.
zlabel(text)
    The label of the z axis (for 3-D axes).
# Examples
## Labels with units and symbols
T = linspace(250, 350, 50);
plot(T, 101.3*exp(-5000*(1./T - 1/373)))
xlabel('Temperature (K)')
ylabel('Pressure (kPa)')
## Three axes
[X, Y] = meshgrid(linspace(-1, 1, 20));
surf(X, Y, X.^2 - Y.^2)
xlabel('x')
ylabel('y')
zlabel('x^2 - y^2')
# See also
title axis text

@ legend
A legend of the plotted objects.

A box naming each line or other plotted object, with a sample of how it is drawn. The labels go to the objects in the order they were plotted; a line's `'DisplayName'` gives its label without listing it here. `'Location'` places the box: `'northeast'` (the default), `'northwest'`, `'south'`, `'best'`, and the others named by the compass, or `'...outside'` beyond the axes.

# Syntax
legend
    Labels from the objects' `DisplayName` (or data1, data2, …).
legend(label1, label2, ...)
    A label for each object, in order.
legend(labels)
    The labels as a cell array.
legend(..., 'Location', 'northeast' | 'best' | ...)
    Where to put it.
legend off
    Remove it.
# Examples
## Labels in order, placed in a corner
x = linspace(0, 2, 50);
plot(x, x, x, x.^2, x, x.^3)
legend('x', 'x^2', 'x^3', 'Location', 'northwest')
## Labels from the lines themselves
t = 0:0.1:5;
plot(t, sin(t), 'DisplayName', 'sine')
hold on
plot(t, cos(t), '--', 'DisplayName', 'cosine')
hold off
legend
# See also
plot title text

@ axis
Set the axis limits and how the axes are shaped.

Sets the limits of all axes at once, or a mode: `equal` makes a unit the same length on each axis (a circle looks round), `tight` fits the limits to the data, `square` makes the axes box square, `ij` puts the y origin at the top (as for images), `off` hides the axes. Without arguments it gives the current limits.

# Syntax
axis([xmin xmax ymin ymax])
    The x and y limits.
axis([xmin xmax ymin ymax zmin zmax])
    With the z limits.
axis equal | tight | square | normal | ij | xy | auto | off | on
    A mode.
lims = axis
    The current limits.
# Examples
## A circle that looks round
t = linspace(0, 2*pi, 100);
plot(cos(t), 2 + sin(t))
axis equal
## Fixed limits, and reading them back
plot(1:10, (1:10).^2)
axis([0 12 0 120])
lims = axis
# See also
xlim ylim daspect

@ grid
Show or hide the grid lines.

Grid lines run across the axes at the tick marks. `grid minor` adds lines between them as well.

# Syntax
grid on | off | minor
    Show, hide, or show with minor lines.
grid
    Switch the major grid on or off.
# Examples
## Grid lines for reading values
x = linspace(0, 10, 200);
plot(x, besselj(0, x))
grid on
## Minor lines on a logarithmic plot
f = logspace(1, 4, 100);
semilogx(f, 20*log10(1 ./ sqrt(1 + (f/1000).^2)))
grid on
grid minor
xlabel('frequency (Hz)')
ylabel('gain (dB)')
# See also
axis xticks

@ xlim, ylim, zlim
The limits of the x, y and z axes.

Each sets the lower and upper limit of one axis, leaving the others as they are; without arguments it gives the current limits. `'auto'` lets the axis fit the data again. A limit of `-Inf` or `Inf` keeps that end automatic.

# Syntax
xlim([xmin xmax])
    The x limits.
lims = xlim
    The current x limits.
xlim auto
    Back to limits fitted to the data.
ylim([ymin ymax])
    The y limits.
zlim([zmin zmax])
    The z limits.
# Examples
## Zooming in on part of a curve
x = linspace(0, 20, 500);
plot(x, sin(x) ./ x)
xlim([0 10])
ylim([-0.3 1.1])
## Reading the limits
plot([2 7 4])
lims = ylim
# See also
axis xticks

@ text
Text at a point of the axes.

Places text at the point `(x, y)` in the units of the data, so it moves with the data when the axes are zoomed. By default the text starts at the point and is centred on it vertically; `'HorizontalAlignment'` and `'VerticalAlignment'` move it, and `'FontSize'`, `'Color'` and `'Rotation'` change its look. Several points with a cell array of texts label each one.

# Syntax
text(x, y, s)
    Text `s` at the point (x, y).
text(x, y, z, s)
    At a point of 3-D axes.
h = text(..., 'Name', value)
    With text properties, and the text objects.
# Examples
## Marking points on a curve
x = linspace(0, 2*pi, 100);
plot(x, sin(x))
text(pi/2, 1, '  maximum')
text(3*pi/2, -1, '  minimum')
ylim([-1.3 1.3])
## A label for each point
x = [1 2 3 4];
y = [3 1 4 2];
plot(x, y, 'o')
text(x + 0.1, y, {'A', 'B', 'C', 'D'})
xlim([0 5])
ylim([0 5])
# See also
title annotation gtext

@ colorbar
Show the colour scale beside the axes.

A bar showing which colour stands for which value, for surfaces, images, contours and scatter plots coloured by value. Its limits follow the axes' colour limits (`clim`). `colorbar off` removes it.

# Syntax
colorbar
    A colour scale at the right of the axes.
colorbar(location)
    At another place: `'eastoutside'`, `'southoutside'`, `'north'`, ….
colorbar off
    Remove it.
c = colorbar
    With its handle, to set its `Label` and other properties.
# Examples
## The scale of an image
[X, Y] = meshgrid(linspace(-3, 3, 60));
imagesc(peaks(60))
colorbar
## A scale below the axes
contourf(peaks(40), 12)
colorbar('southoutside')
# See also
colormap clim imagesc surf

@ colormap
Set or get the colours of the figure's colour scale.

The colormap is a list of colours, one row of `[r g b]` per colour, through which surfaces, images and other objects coloured by value pick their colours: the lowest value takes the first row and the highest the last. Named maps include `parula` (the default), `turbo`, `jet`, `hot`, `cool`, `gray` and `bone`; a matrix of your own works too.

# Syntax
colormap(name)
    A named map.
colormap(name, n)
    A named map of `n` colours.
colormap(map)
    A matrix of colours (values from 0 to 1).
map = colormap
    The current map.
colormap(ax, ...)
    The map of the axes `ax` alone.
# Examples
## A named map
surf(peaks(40))
shading interp
colormap hot
colorbar
## A map for each axes
> With axes first, `colormap` sets that axes' map alone.
Z = peaks(60);
subplot(1, 2, 1)
imagesc(Z)
axis image off
colormap(gca, 'parula')
subplot(1, 2, 2)
imagesc(Z)
axis image off
colormap(gca, 'gray')
## A few distinct colours
imagesc(magic(4))
colormap(turbo(4))
colorbar
# See also
colorbar parula turbo clim

@ close
Close figures.

Closes the current figure, a given one, or all of them. A figure whose `CloseRequestFcn` was set runs that first.

# Syntax
close
    The current figure.
close(n)
    Figure `n` (or the figure with handle `n`).
close all
    Every figure.
# Examples
## Closing some, then all
figure(1); plot(1:3)
figure(2); plot(3:-1:1)
figure(3); plot([1 3 2])
close(2)
open = sort([findobj('Type', 'figure').Number])
close all
remaining = numel(findobj('Type', 'figure'))
# See also
figure clf delete
