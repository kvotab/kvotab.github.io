@ fitlm
A linear regression model: least squares of a response on its predictors.

Fits the response as a linear combination of terms of the predictors, by least squares, and returns a model object: shown, it gives the coefficients with their standard errors, t statistics and p-values, and the R². The terms come from a name (`'linear'`, `'interactions'`, `'quadratic'`, `'polyN'`) or a formula such as `'y ~ x1 + x2*x3'`, where `*` adds the products and `-1` drops the intercept. A table's variables give the names; a categorical predictor becomes a dummy for each level but the first. The model goes to `predict`, `coefCI`, `coefTest`, `anova` and `plotResiduals`.

# Syntax
mdl = fitlm(X, y)
    A linear model of the columns of `X`, with an intercept.
mdl = fitlm(X, y, modelspec)
    With other terms: `'constant'`, `'linear'`, `'interactions'`, `'purequadratic'`, `'quadratic'`, `'polyN'`.
mdl = fitlm(tbl, 'y ~ x1 + x2*x3')
    From a table, by a formula.
mdl = fitlm(..., 'Intercept', false, 'Weights', w, 'RobustOpts', 'on')
    Without an intercept, weighted, or robust.
# Examples
## A straight line, and the model's numbers
x = (1:10)';
y = [3.1 4.9 7.2 8.8 11.1 13.2 14.8 17.1 19.0 21.2]';
mdl = fitlm(x, y)
mdl.Rsquared.Ordinary
## Two predictors from a table, with an interaction
rng default
x1 = rand(40, 1);
x2 = rand(40, 1);
y = 1 + 2*x1 - 3*x2 + 4*x1.*x2 + 0.05*randn(40, 1);
tbl = table(x1, x2, y);
mdl = fitlm(tbl, 'y ~ x1*x2');
mdl.Coefficients
# See also
predict fitglm fitnlm regress anova

@ fitglm
A generalized linear model: a response from the normal, binomial, Poisson, gamma or inverse Gaussian distribution, its mean a function of the linear predictor.

When the response is a count, a proportion or a positive skewed quantity, its mean is linked to a linear combination of the predictors through a link function: the log for Poisson counts, the logit for binomial proportions (logistic regression). The coefficients are fitted by maximum likelihood; the model shows them with their tests and the deviance.

# Syntax
mdl = fitglm(X, y)
    A normal model (the same as `fitlm`).
mdl = fitglm(X, y, modelspec, 'Distribution', 'poisson')
    Counts, with the log link.
mdl = fitglm(X, [k n], 'linear', 'Distribution', 'binomial')
    Successes out of trials, with the logit link.
mdl = fitglm(tbl, 'y ~ x1 + x2', 'Distribution', 'binomial', 'Link', 'probit')
    From a table, with another link.
# Examples
## Poisson counts
rng default
x = linspace(0, 2, 60)';
y = poissrnd(exp(0.5 + 1.2*x));
mdl = fitglm(x, y, 'linear', 'Distribution', 'poisson');
mdl.Coefficients
## Logistic regression of passes out of trials
dose = [1 2 3 4 5]';
passed = [2 5 11 16 19]';
n = 20*ones(5, 1);
mdl = fitglm(dose, [passed n], 'linear', 'Distribution', 'binomial');
b = mdl.Coefficients.Estimate'
predict(mdl, 3.5)

glmfit fitlm predict

@ fitnlm
A nonlinear regression model: least squares of a model function's coefficients.

The model function `modelfun(b, X)` gives the fitted values for coefficients `b`; starting from `beta0`, the coefficients that make the squared residuals smallest are found. The model object shows them with standard errors and p-values, and goes to `predict`.

# Syntax

mdl = fitnlm(..., 'Weights', w, 'CoefficientNames', names)

# Examples

@ coefCI, coefTest
Confidence intervals of a model's coefficients, and a linear hypothesis test on them.

`coefCI` gives an interval for each coefficient (95% unless `alpha` is given), a row each. `coefTest` tests `H*b = c`: with no `H`, that every coefficient but the intercept is zero (the model's F test).

# Syntax

    At level 1 - alpha.

    Are all coefficients but the intercept zero?
[p, F, r] = coefTest(mdl, H, c)
    Is `H*b` equal to `c`?
# Examples
## Intervals, and two coefficients tested equal
rng default
X = rand(50, 2);
y = 1 + 2*X(:, 1) + 2*X(:, 2) + 0.1*randn(50, 1);
mdl = fitlm(X, y);
coefCI(mdl)
p = coefTest(mdl, [0 1 -1])

@ fitlme, fixedEffects, randomEffects, covarianceParameters, fitted, residuals, response
A linear mixed-effects model, and what it holds.

Data in groups (patients, schools, plots) often share an offset or a slope within each group. A mixed-effects model has fixed effects, as a linear model does, and random effects: a term `(1 | g)` gives each group of `g` its own intercept, `(1 + x | g)` its own intercept and slope. They are fitted by maximum likelihood (or REML). `fixedEffects` gives the coefficients, `randomEffects` each group's predicted effects, `covarianceParameters` their covariance and the residual variance, and `fitted`, `residuals` and `response` the values.

# Syntax
lme = fitlme(tbl, formula)
    Fitted by maximum likelihood.
lme = fitlme(tbl, formula, 'FitMethod', 'REML')
    By restricted maximum likelihood.
beta = fixedEffects(lme)
    The fixed effects.
B = randomEffects(lme)
    The predicted random effects.
psi = covarianceParameters(lme)
    The random terms' covariance matrices.
yfit = fitted(lme)
    The fitted values (with the random effects).
r = residuals(lme)
    The residuals.
y = response(lme)
    The response.
# Examples
## Groups with their own offsets
rng default
g = repelem((1:6)', 8);
x = repmat((1:8)', 6, 1);
offset = 2*randn(6, 1);
y = 1 + 0.5*x + offset(g) + 0.3*randn(48, 1);
tbl = table(categorical(g), x, y, 'VariableNames', {'g', 'x', 'y'});
lme = fitlme(tbl, 'y ~ x + (1 | g)');
fixedEffects(lme)'
[randomEffects(lme) offset - mean(offset)]
