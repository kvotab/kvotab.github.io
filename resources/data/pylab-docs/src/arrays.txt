@ rand
Random numbers drawn evenly from the open interval (0, 1).

Every value between 0 and 1 is equally likely. For another interval scale and shift: `a + (b - a)*rand(...)` is even on (a, b). The numbers come from a Mersenne Twister generator; `rng` sets its seed, so that a run can be repeated. `rng default` gives the generator's usual first numbers.

b = 20;

> The share of points in the unit square that fall inside the quarter circle is close to pi/4.

@ colon

@ realmax, realmin
The largest finite and the smallest positive normalized floating-point numbers.

`realmax` is about 1.8e308 for double; anything larger overflows to `Inf`. `realmin` is about 2.2e-308, the smallest double with full precision (smaller numbers down to about 4.9e-324 exist with fewer digits). `'single'` gives the limits of single precision.

# Syntax
v = realmax
    The largest finite double.
v = realmax('single')
    The largest finite single.
v = realmin
    The smallest positive normalized double.
v = realmin('single')
    The smallest positive normalized single.
# Examples
## The limits, and past them
big = realmax
small = realmin
realmax * 2
realmax('single')

@ flintmax
The largest integer up to which floating point holds every integer exactly (2^53 for double).

Every integer up to `flintmax` (9007199254740992 for double) is a double exactly; past it, doubles are two apart, then four, so some integers have no double of their own. Integer counts above it belong in `int64` or `uint64`.

# Syntax
v = flintmax
    2^53.
v = flintmax('single')
    2^24.
# Examples
## The last exact integer
f = flintmax;
fprintf('%.0f\n', f)
f + 1 == f
f - 1 == f
flintmax('single')

@ blkdiag

The matrices go down the diagonal in order, each in its own rows and columns, with zeros elsewhere.

@ toeplitz
A Toeplitz matrix: constant along each diagonal.

The first column is `c` and the first row is `r`; every diagonal repeats its first element. With one argument the matrix is symmetric (Hermitian for complex values). Toeplitz matrices describe convolution and the covariances of a stationary series.

# Syntax
T = toeplitz(c, r)
    First column `c`, first row `r` (`c(1)` is used where they meet).
T = toeplitz(r)
    The symmetric Toeplitz matrix of `r`.
# Examples
## Symmetric, and from a column and a row
T = toeplitz([1 2 3 4])
T2 = toeplitz([1 5 6], [1 2 3 4])
# See also
hankel vander conv

@ hankel
A Hankel matrix: constant along each anti-diagonal.

The first column is `c`; with `r`, the last row is `r`, and without it the matrix is zero below the anti-diagonal. Each anti-diagonal (running up to the right) repeats one value.

# Syntax
H = hankel(c)
    First column `c`, zeros below the anti-diagonal.
H = hankel(c, r)
    First column `c` and last row `r`.
# Examples
## Both forms
H = hankel([1 2 3])
H2 = hankel([1 2 3], [3 4 5 6])
# See also
toeplitz vander

@ vander
The Vandermonde matrix of a vector: its columns are powers of the vector.

Column j is `v.^(n-j)`, so the last column is ones. Solving with it fits the polynomial through the points (`polyfit` does this more stably).

# Syntax
V = vander(v)
    The Vandermonde matrix, highest power first.
# Examples
## The polynomial through three points
x = [1 2 3];
y = [2 3 6];
V = vander(x)
p = V \ y'
# See also

@ hilb, invhilb
The Hilbert matrix, H(i,j) = 1/(i+j-1), and its exact inverse.

The Hilbert matrix is a classic example of an ill-conditioned matrix: its condition number grows very fast with its size, so linear systems with it lose digits. `invhilb` gives its inverse exactly (integers), for checking how much a numerical inverse loses.

# Syntax
H = hilb(n)
    The n-by-n Hilbert matrix.
H = invhilb(n)
    Its inverse, exact.
# Examples
## The matrix, its condition, and its inverse
H = hilb(3)
cond(hilb(8))
invhilb(3)
## How much a numerical inverse loses
n = 10;
err = norm(inv(hilb(n)) - invhilb(n)) / norm(invhilb(n))
# See also
cond inv pascal

@ pascal
The Pascal matrix: binomial coefficients, symmetric and positive definite.

Element (i, j) is the binomial coefficient `nchoosek(i+j-2, j-1)`, so the anti-diagonals are rows of Pascal's triangle. Its determinant is 1 and its inverse has integer entries.

# Syntax
P = pascal(n)
    The n-by-n Pascal matrix.
# Examples
## The matrix and its determinant
P = pascal(5)
det(P)
# See also
nchoosek magic hilb

@ compan
The companion matrix of a polynomial; its eigenvalues are the polynomial's roots.

For coefficients `p` (highest power first), a square matrix whose characteristic polynomial is `p`: its eigenvalues are the roots, which is how `roots` finds them.

# Syntax
C = compan(p)
    The companion matrix of `p`.
# Examples
## The roots from the eigenvalues
p = [1 -6 11 -6];
C = compan(p)
sort(eig(C))'
roots(p)'
# See also
roots poly eig

@ wilkinson, rosser
Eigenvalue test matrices: Wilkinson's, and Rosser's 8-by-8.

`wilkinson(n)` is symmetric tridiagonal, with ones beside the diagonal and |k| on it; its largest eigenvalues come in nearly equal pairs, a test for eigenvalue solvers. `rosser` is a symmetric 8-by-8 integer matrix with a double eigenvalue, three nearly equal ones, a zero and a nearly zero one.

# Syntax
W = wilkinson(n)
    The n-by-n Wilkinson matrix.
R = rosser
    Rosser's matrix.
# Examples
## Nearly equal eigenvalues
W = wilkinson(7)
e = eig(wilkinson(21));
e(end-1:end)'
## Rosser's eigenvalues
format long g
eig(rosser)

eig hilb

@ accumarray
Gather values by index and combine those that share one (a sum by default).

Each value goes to the place its index (a row of `subs`) names; values sent to the same place are summed, or combined by `fun`. With group numbers as the indices it computes a statistic for each group, as `unique`'s third output gives them.

# Syntax
A = accumarray(subs, vals)
    Sums of `vals` by the indices in `subs`.
A = accumarray(subs, vals, sz)
    With the size of the result.
A = accumarray(subs, vals, sz, fun)
    Combined by `fun` instead of summed, such as `@max` or `@(x) {x}`.
A = accumarray(subs, vals, sz, fun, fillval)
    With `fillval` where no value went.
# Inputs
subs — matrix, vector or cell array of index vectors
    A column for each dimension of the result (a column of positions for a vector result).
vals — vector or scalar
    The values, one for each row of `subs` (a scalar goes to every one).
# Examples
## Counting and summing by group
g = [1 3 1 2 3 3];
v = [10 20 30 40 50 60];
counts = accumarray(g', 1)'
sums = accumarray(g', v')'
## The largest value of each group, and an empty group
accumarray([1; 3; 3; 1], [4; 2; 8; 6], [4 1], @max, NaN)'
## A table of counts from two indices
pairs = [1 1; 2 1; 1 1; 2 2; 1 2];
T = accumarray(pairs, 1)
