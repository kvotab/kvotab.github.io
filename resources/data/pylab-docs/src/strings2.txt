@ strings
A string array of empty strings.

Strings (in double quotes) are whole texts held as single elements, where character arrays (in single quotes) are rows of characters. `strings(m, n)` makes an m-by-n array of empty strings to fill in.

# Syntax
s = strings(m, n)
    An m-by-n array of "".
s = strings(sz)
    Of the size `sz`.
# Examples
## Filled in a loop
s = strings(1, 3);
for k = 1:3
    s(k) = "item " + k;
end
s
# See also
string char

@ cellstr
A cell array of character vectors.

From a character array, one cell per row with the trailing blanks removed; from a string array, one cell per string; a cell array of text stays as it is.

# Syntax
C = cellstr(A)
    The cells.
# Examples
## From a padded character array and from strings
C = cellstr(char('one', 'three'))
cellstr(["a" "bc"])

@ int2str, mat2str
Numbers as text: rounded to integers, or a whole matrix in the language's brackets.

`int2str` rounds and writes the numbers as `num2str` would; `mat2str` writes a matrix so that evaluating the text gives it back (to 15 significant digits, or `precision`), with `true`/`false` for logical values and quotes for characters.

# Syntax
s = int2str(x)
    Rounded, as text.
s = mat2str(A)
    In brackets.
s = mat2str(A, precision)
    To a number of significant digits.
# Examples
## Text that evaluates back
int2str([2.4 2.5 -3.7])
s = mat2str([1 2; 3 4.5])
isequal(eval(s), [1 2; 3 4.5])
mat2str(pi, 4)
mat2str([true false])
# See also
num2str str2num

@ str2num
Text evaluated as an expression, and its value.

The text may hold numbers, matrices in brackets and expressions (`'[1 2; 3 4]'`, `'pi/2'`); `ok` is false when it cannot be evaluated. As it evaluates the text, use `str2double` for plain numbers from untrusted text.

# Syntax
x = str2num(s)
    The value.
[x, ok] = str2num(s)
    With whether it worked.
# Examples
## A matrix, an expression, and text that is not one
str2num('[1 2; 3 4]')
str2num('sqrt(16) + 1')
[x, ok] = str2num('hello world')

str2double eval mat2str

@ split, splitlines, join
Strings split at a separator or at line breaks, and joined with one; or two tables joined by their keys.

`split` splits at white space unless a separator (or several) is given; one string gives a column, several (with the same number of parts) a matrix. `splitlines` splits at line breaks. `join` puts the elements of a string array together with a space or a separator, along the last dimension. For tables, `join(A, B)` adds B's other variables to A, each row matched by its keys.

# Syntax
parts = split(s)
    At white space.
parts = split(s, delimiter)
    At a separator.
lines = splitlines(s)
    At line breaks.
s = join(parts, delimiter)
    Joined.
T = join(A, B, 'Keys', keys)
    Two tables.
# Examples
## Split and joined again
parts = split("red,green,blue", ",")
join(parts, " / ")
lines = splitlines("first" + newline + "second")
## Two tables joined by a key
A = table([1; 2; 3], ["x"; "y"; "x"], 'VariableNames', {'Id', 'Group'});
B = table(["x"; "y"], [10; 20], 'VariableNames', {'Group', 'Weight'});
join(A, B)

@ strtrim, strip, deblank
White space removed from the ends of text.

`strtrim` removes leading and trailing white space; `strip` does too, from one side or both, or another character; `deblank` removes trailing white space and null characters only.

# Syntax
t = strtrim(s)
    Both ends.
t = strip(s, side)
    `'left'`, `'right'` or `'both'`.
t = strip(s, side, character)
    Another character.
t = deblank(s)
    Trailing only.
# Examples
## Three ways of trimming
s = "   data   ";
["[" + strtrim(s) + "]", "[" + strip(s, 'left') + "]", "[" + deblank(s) + "]"]
strip("--title--", 'both', '-')
# See also
pad blanks

@ blanks, pad, strjust
Spaces: a row of them, text padded with them, and text shifted within its width.

`blanks(n)` is a row of n spaces. `pad` pads texts to the longest (or to n) with spaces or another character, on the right unless `'left'` or `'both'`. `strjust` shifts the text of each row of a character array to the right, left or centre within the array's width.

# Syntax
s = blanks(n)
    `n` spaces.
t = pad(s, n, side, character)
    Padded.
t = strjust(s, how)
    `'right'` (the default), `'left'` or `'center'`.
# Examples
## A column of names lined up
names = ["Ada"; "Grace"; "Al"];
pad(names)
pad(names, 8, 'left', '.')
strjust(['a  '; 'bb '], 'right')
['[' blanks(3) ']']

@ strcmp, strcmpi, strncmp, strncmpi
Texts compared: whole and exact, ignoring case, or by their first n characters.

True when the texts are identical (`strcmp`), identical ignoring case (`strcmpi`), or agree in their first n characters (`strncmp`, `strncmpi`). With a cell array or string array, a result for each element; text never equals a number.

# Syntax
tf = strcmp(s1, s2)
    Identical.
tf = strcmpi(s1, s2)
    Ignoring case.
tf = strncmp(s1, s2, n)
    The first `n` characters.
tf = strncmpi(s1, s2, n)
    The first `n`, ignoring case.
# Examples
## Four ways of comparing
strcmp('Apple', {'apple', 'Apple', 'Apricot'})
strcmpi('Apple', {'apple', 'Apple', 'Apricot'})
strncmp('Apple', {'apple', 'Apple', 'Apricot'}, 2)
strncmpi('Apple', {'apple', 'Apple', 'Apricot'}, 2)

@ startsWith, endsWith, matches
Whether text starts with, ends with, or is a pattern (or one of several).

The pattern is text, a list of texts (any of which will do), or a pattern object; `'IgnoreCase', true` ignores case.

# Syntax

    Starts with it.
tf = endsWith(s, pattern)
    Ends with it.
tf = matches(s, pattern)
    Is it.
tf = startsWith(..., 'IgnoreCase', true)
    Ignoring case.
# Examples

files = ["data.csv", "notes.txt", "Data2.CSV", "plot.png"];
endsWith(files, ".csv", 'IgnoreCase', true)
startsWith(files, ["data", "plot"])
matches(files, "notes.txt")

@ strfind, strmatch
Where a pattern occurs in text, and which rows of a list start with some text.

`strfind` gives the starting index of every occurrence (overlapping ones too); for a cell array, a cell of them. `strmatch` gives the rows of a character matrix (or elements of a cell array) that start with the text, or with `'exact'` are it.

# Syntax

k = strmatch(s, list)

    The rows that are `s`.
# Examples
## Occurrences, and rows of a list

strmatch('ma', {'max', 'min', 'mean', 'map'})
strmatch('max', char('max', 'maxima'), 'exact')

@ regexp, regexpi
Text matched by a regular expression.

A regular expression describes text: `\d` a digit, `\w` a word character, `+` one or more, `(...)` a token, `(?<name>...)` a named token. The outputs come in the order of the keywords asked for (`'match'`, `'tokens'`, `'names'`, `'start'`, `'end'`, `'split'`); without keywords, the starting indices. `'once'` gives the first match only, not in a cell. `regexpi` ignores case.

# Syntax
startIndex = regexp(s, expr)
    Where matches start.
[tok, mat] = regexp(s, expr, 'tokens', 'match')
    The tokens and matches.
names = regexp(s, expr, 'names')
    Named tokens as a struct.
parts = regexp(s, expr, 'split')
    The text between matches.
t = regexp(s, expr, 'match', 'once')
    The first match.
# Examples
## Numbers, named parts and splits
s = 'x = 12, y = 345, z = 6';
regexp(s, '\d+', 'match')
d = regexp('2026-11-05', '(?<year>\d+)-(?<month>\d+)-(?<day>\d+)', 'names')
regexp('a1b22c', '\d+', 'split')
regexpi('Hello HELLO hello', 'hello', 'match')
# See also
regexprep regexptranslate pattern

@ regexprep
The matches of a regular expression replaced.

In the replacement, `$1`, `$2`, ... stand for the tokens; `'once'` replaces the first match only, `'ignorecase'` ignores case.

# Syntax
t = regexprep(s, expr, replace)
    Every match replaced.
t = regexprep(s, expr, replace, 'once')
    The first.
# Examples
## Dates reordered and spaces squeezed
regexprep('2026-11-05', '(\d+)-(\d+)-(\d+)', '$3/$2/$1')
regexprep('too    many   spaces', '\s+', ' ')
# See also
regexp replace

@ regexptranslate
Text escaped for use in a regular expression, or a wildcard turned into one.

`'escape'` puts a backslash before each character that has a meaning in a regular expression; `'wildcard'` turns `*` and `?` into `.*` and `.`, as file names are matched.

# Syntax
t = regexptranslate('escape', s)
    Escaped.
t = regexptranslate('wildcard', s)
    A wildcard as a regular expression.
# Examples
## A literal dot, and a file mask
e = regexptranslate('escape', 'a.b')
regexp('axb a.b', e, 'match')
w = regexptranslate('wildcard', '*.csv')
regexp({'a.csv', 'b.txt'}, ['^' w '$'], 'match', 'once')

@ dec2bin, bin2dec, dec2hex, hex2dec, dec2base, base2dec

`dec2bin`, `dec2hex` and `dec2base` (bases 2 to 36) write nonnegative integers as digits, at least `n` of them when given; several numbers give rows of the same width. A negative number is written in two's complement. `bin2dec`, `hex2dec` and `base2dec` read the digits back.

# Syntax

d = bin2dec(s)
    Back.
s = dec2hex(d, n)
    Hexadecimal digits.
d = hex2dec(s)
    Back.
s = dec2base(d, base, n)
    In another base.
d = base2dec(s, base)
    Back.
# Examples
## The same numbers in three bases
dec2bin([5 12], 8)
bin2dec('1100')
dec2hex(255)
hex2dec('FF')
dec2base(35, 36)
base2dec('Z', 36)
dec2bin(-1, 8)

# Examples
