@ makedist
A probability distribution object with the parameters given.

The object holds a distribution and its parameters, and goes to the functions that work on any distribution: `pdf`, `cdf`, `icdf`, `random`, `mean`, `median`, `std`, `var`, `iqr` and `truncate`. Its parameters are its properties, so they can be read and changed by name. Parameters left out keep their defaults (the normal's `mu` 0 and `sigma` 1). `makedist` with no input lists the distributions it knows.

# Syntax
pd = makedist(name)
    The distribution with its default parameters.
pd = makedist(name, 'param', value, ...)
    With parameters given by name.
names = makedist
    The names of the distributions.
# Inputs
name — text
    `'Normal'`, `'Lognormal'`, `'Exponential'`, `'Gamma'`, `'Weibull'`, `'Beta'`, `'Uniform'`, `'Poisson'`, `'Binomial'`, `'Triangular'`, `'Logistic'` and the others `makedist` lists.
# Examples
## A normal distribution and its numbers
pd = makedist('Normal', 'mu', 10, 'sigma', 2)
[mean(pd) std(pd)]
cdf(pd, 12) - cdf(pd, 8)
icdf(pd, 0.975)
## Its parameters as properties
pd = makedist('Weibull', 'A', 2, 'B', 1.5);
pd.B = 3;
median(pd)
## Densities of three distributions
x = linspace(0, 6, 300);
plot(x, pdf(makedist('Exponential', 'mu', 1), x), ...
     x, pdf(makedist('Gamma', 'a', 3, 'b', 0.7), x), ...
     x, pdf(makedist('Lognormal', 'mu', 0.5, 'sigma', 0.4), x))
legend('exponential', 'gamma', 'lognormal')
# See also
fitdist pdf cdf random truncate

@ fitdist
A probability distribution object fitted to data.

Estimates the distribution's parameters from the data by maximum likelihood (the normal's and lognormal's sigma being the unbiased estimate), and returns an object that knows its data: `paramci` gives the parameters' confidence intervals and `negloglik` the likelihood. `'Kernel'` gives a smooth nonparametric fit instead. With `'By'`, a fit for each group.

# Syntax
pd = fitdist(x, name)
    The named distribution fitted to the data `x`.
pd = fitdist(x, 'Kernel', 'Kernel', kernel, 'Bandwidth', bw)
    A kernel density fit.
[pds, names] = fitdist(x, name, 'By', group)
    A fit for each group, in a cell array.
# Examples
## A Weibull fit and its intervals
rng default
x = wblrnd(2, 1.5, 200, 1);
pd = fitdist(x, 'Weibull')
paramci(pd)
## The fit against the data
rng default
x = gamrnd(3, 1, 500, 1);
pd = fitdist(x, 'Gamma');
histogram(x, 'Normalization', 'pdf')
hold on
t = linspace(0, max(x), 200);
plot(t, pdf(pd, t), 'LineWidth', 2)
hold off
# See also
makedist mle paramci negloglik

@ mle
Maximum likelihood estimates of a distribution's parameters, with confidence intervals.

The parameters that make the data most probable. Without a distribution the data are taken to be normal, and sigma is the likelihood's own (normalized by N, not N-1). The intervals are in two rows, lower ends first.

# Syntax
phat = mle(x)
    The normal mean and standard deviation.
[phat, pci] = mle(x, 'Distribution', name, 'Alpha', alpha)
    For a named distribution, with confidence intervals.
phat = mle(x, 'Distribution', 'Binomial', 'NTrials', n)
    For the binomial, with the number of trials.
# Examples
## Normal and exponential estimates
x = [4.2 5.1 3.8 4.9 5.5 4.4];
phat = mle(x)
[std(x, 1) std(x)]
rng default
[phat, pci] = mle(exprnd(3, 100, 1), 'Distribution', 'Exponential')

@ pdf, cdf, icdf, random
The density, distribution function, quantiles and random numbers of any distribution.

Given a distribution object (from `makedist` or `fitdist`), or a distribution's name and its parameters in the order its own function takes them (`normpdf(x, mu, sigma)` becomes `pdf('Normal', x, mu, sigma)`). For a discrete distribution, `pdf` gives the probabilities. `cdf` with `'upper'` gives the probability above `x`.

# Syntax
y = pdf(pd, x)
    The density of the distribution object at `x`.
y = pdf(name, x, A, B, C)
    Of a named distribution with its parameters.
p = cdf(pd, x)
    The probability at or below `x`.
p = cdf(..., 'upper')
    The probability above `x`.
x = icdf(pd, p)
    The quantiles for the probabilities `p`.
r = random(pd, m, n)
    An m-by-n array of random numbers (one number without a size).
r = random(name, A, B, C, m, n)
    From a named distribution.
# Examples
## By name and by object
pdf('Normal', 0, 0, 1)
cdf('Poisson', 2, 3)
pd = makedist('Exponential', 'mu', 2);
[cdf(pd, 1) cdf(pd, 1, 'upper')]
icdf('t', 0.975, 10)
## Random numbers
rng default
r = random('Binomial', 10, 0.5, 1, 8)

@ truncate
A distribution object limited to an interval, its probability there scaled up to 1.

The truncated distribution keeps the shape of the original between `lower` and `upper` and has no probability outside: a normal measurement that cannot be negative, for one. Its random numbers fall in the interval.

# Syntax
t = truncate(pd, lower, upper)
    `pd` limited to [lower, upper].
# Examples
## A normal distribution kept positive
pd = makedist('Normal', 'mu', 1, 'sigma', 2);
t = truncate(pd, 0, Inf);
[mean(pd) mean(t)]
[cdf(t, 0) pdf(t, 1) / pdf(pd, 1)]
x = linspace(-4, 6, 300);
plot(x, pdf(pd, x), x, pdf(t, x))
legend('normal', 'truncated at 0')

makedist pdf random

The confidence intervals of a fitted distribution object's parameters, and its negative log-likelihood.

`paramci` gives an interval for each parameter, lower ends in the first row; `negloglik` the negative log-likelihood of the fit for its data, smaller for a better fit (for comparing distributions fitted to the same data, as with an information criterion).

# Syntax

    95% intervals, a column for each parameter.

    The negative log-likelihood.
# Examples
## Which of two distributions fits better
rng default

pdL = fitdist(x, 'Lognormal');
pdG = fitdist(x, 'Gamma');
[negloglik(pdL) negloglik(pdG)]
paramci(pdL)

@ mvnpdf, mvncdf, mvnrnd
The multivariate normal distribution: its density, its distribution function, and random vectors.

Each row of `X` is a point, `mu` the mean (a row) and `Sigma` the covariance matrix; left out, the means are zero and the covariance is the identity. `mvncdf` gives the probability that every component is below the point's, by numerical integration (good to about 1e-5). `mvnrnd` gives a row for each random vector.

# Syntax
y = mvnpdf(X, mu, Sigma)
    The density at each row of `X`.
p = mvncdf(X, mu, Sigma)
    The probability below each row of `X`.
R = mvnrnd(mu, Sigma, n)
    `n` random vectors, a row each.
# Examples
## Correlated normal vectors
rng default

Sigma = [1 0.8; 0.8 1];
R = mvnrnd(mu, Sigma, 2000);
corrcoef(R)
mvncdf([0 0], mu, Sigma)
## The density as contours
[X1, X2] = meshgrid(linspace(-3, 3, 60));
Y = reshape(mvnpdf([X1(:) X2(:)], [0 0], [1 0.8; 0.8 1]), size(X1));

axis equal

@ randsample, datasample
Random samples: of numbers or values, without replacement unless asked; of the elements or rows of data.

`randsample(n, k)` draws `k` of the numbers 1 to n without replacement; given a population, it draws from its values, with replacement when asked and with weights. `datasample` draws elements of a vector or rows of a matrix, with replacement unless `'Replace'` is false, and also returns their indices.

# Syntax
y = randsample(n, k)
    `k` different numbers from 1 to n.
y = randsample(population, k, replace, w)
    From the population's values, with or without replacement, with weights `w`.
y = datasample(data, k)
    `k` elements (or rows), with replacement.
[y, idx] = datasample(..., 'Replace', false, 'Weights', w)
    Without replacement or with weights, and the indices drawn.
# Examples
## Draws without and with replacement
rng default
randsample(10, 4)'
randsample({'a', 'b', 'c'}, 5, true)
## Weighted draws, counted
rng default
y = randsample([1 2 3], 1000, true, [0.6 0.3 0.1]);
histcounts(y, 0.5:3.5)
## Rows of a matrix
rng default
A = magic(5);
[rows, idx] = datasample(A, 2, 'Replace', false)

The bell curve with mean `mu` and standard deviation `sigma`. About 68% of its probability lies within one standard deviation of the mean and 95% within 1.96 of them. Sums of many small independent effects tend to it, and measurement errors are often taken to follow it.

    Estimates of the parameters from the data `x`.

@ raylpdf, raylcdf, raylinv, raylrnd, raylstat, raylfit
The Rayleigh distribution: density, distribution function, quantiles, random numbers, mean and variance, and fit.

The length of a two-dimensional vector whose components are independent normal numbers of mean 0 and standard deviation `B`: the model of wind speeds and of the amplitude of noise.

# Syntax
y = raylpdf(x, B)
    The density at `x`.
p = raylcdf(x, B)
    The probability at or below `x`.
q = raylcdf(x, B, 'upper')
    The probability above `x`, computed as such (accurate far into the tail).
x = raylinv(p, B)
    The quantiles: the values below which the probabilities `p` lie.
r = raylrnd(B)
    Random numbers, one for each element of the parameters.
r = raylrnd(B, m, n)
    An m-by-n array of random numbers.
r = raylrnd(B, [m n ...])
    With the size as one vector.
[m, v] = raylstat(B)
    The mean and the variance.
phat = raylfit(x)
    Estimates of the parameters from the data `x`.
[phat, pci] = raylfit(x, alpha)
    With confidence intervals (95% unless `alpha` is given).
# Inputs
x — array
    The values.
p — array
    Probabilities, between 0 and 1.
B — number or array
    The scale (1 when left out).
# Examples
## From two normal components
rng default
B = 2;
r = hypot(normrnd(0, B, 5000, 1), normrnd(0, B, 5000, 1));
[mean(r) raylstat(B)]
phat = raylfit(r)
