@ iddata, idinput
Measured data for system identification, and input signals to measure with.

`iddata` holds an output y and an input u (a column each, or several), sampled every Ts seconds, with names and units: `data.y` and `data.u` are the signals, `data(k)` picks samples, and `detrend`, `size` and `plot` take it. A time series has no input (`[]`). `idinput` makes an input for an experiment: random Gaussian (`'rgs'`), random binary (`'rbs'`), pseudorandom binary of maximum length (`'prbs'`) or a sum of sines (`'sine'`), within a band of frequencies (fractions of the Nyquist frequency) and between two levels. A binary input excites the system as strongly as its limits allow.

# Syntax
data = iddata(y, u, Ts)
    Output and input, sampled every Ts.
data = iddata(y, [], Ts)
    A time series.
data = iddata(y, u, Ts, 'OutputName', name, 'InputName', name)
    Named.
u = idinput(N, type, band, levels)
    An input signal of N samples.
# Examples
## An experiment on a simulated system
u = idinput(300, 'prbs', [0 0.3], [-1 1]);
y = filter([0 0.5 0.3], [1 -1.2 0.5], u) + 0.05*randn(300, 1);
data = iddata(y, u, 0.1, 'OutputName', 'level', 'InputName', 'pump')
size(data)
plot(data)
# See also
arx compare detrend

@ arx, ar
Linear models by least squares: ARX models with an input, AR models of time series.

An ARX model is A(q) y(t) = B(q) u(t - nk) + e(t): na past outputs and nb past inputs, nk samples of delay, the coefficients found by least squares. It is also a discrete transfer function B/A, so that `step`, `bode`, `lsim` and the rest take it. `ar` fits A(q) y(t) = e(t) to a time series, by least squares or (`'yw'`) the Yule-Walker equations.

# Syntax
sys = arx(data, [na nb nk])
    An ARX model.
sys = ar(y, n)
    An AR model of order n.
sys = ar(y, n, 'yw')
    By the Yule-Walker equations.
# Examples
## The system found again
> The data come from A = 1 - 1.2 q^-1 + 0.5 q^-2 and B = 0.5 q^-1 + 0.3 q^-2, with noise.
u = idinput(400, 'prbs', [0 0.3]);
e = 0.05*randn(400, 1);
y = filter([0 0.5 0.3], [1 -1.2 0.5], u) + filter(1, [1 -1.2 0.5], e);
m = arx(iddata(y, u, 0.1), [2 2 1])
step(m)
## A series that remembers
x = filter(1, [1 -0.8], randn(1000, 1));
a = ar(x, 1);
a.A
# See also
armax oe n4sid compare

@ armax, oe, bj
Polynomial models with their own noise: ARMAX, output-error and Box-Jenkins.

These fit by prediction error minimization, each with a noise model of its own. ARMAX: A(q) y(t) = B(q) u(t - nk) + C(q) e(t), the noise filtered through C/A; output error: y(t) = B(q)/F(q) u(t - nk) + e(t), white noise on the output, the model fitted to the simulated output; Box-Jenkins: y(t) = B(q)/F(q) u(t - nk) + C(q)/D(q) e(t), the system and the noise each with its own poles.

# Syntax
sys = armax(data, [na nb nc nk])
    An ARMAX model.
sys = armax(y, [na nc])
    An ARMA model of a time series.
sys = oe(data, [nb nf nk])
    An output-error model.
sys = bj(data, [nb nc nd nf nk])
    A Box-Jenkins model.
# Examples
## White noise on the output
> The noise here is added to the output, so an output-error model has the right structure; ARX, which assumes noise filtered through 1/A, is pulled away from the system.
u = idinput(500, 'rbs', [0 0.5]);
y = filter([0 0.4], [1 -0.7], u) + 0.3*randn(500, 1);
data = iddata(y, u, 1);
m1 = oe(data, [1 1 1]);
m2 = arx(data, [1 1 1]);
[m1.F; m2.A]
[m1.B; m2.B]
m3 = armax(data, [1 1 1 1]);
m3.C
# See also
arx compare polydata

@ n4sid, ssest
State-space models found from data: by subspace identification, and refined by prediction errors.

`n4sid` finds a model of nx states in innovations form, x(t+1) = A x(t) + B u(t) + K e(t), y(t) = C x(t) + D u(t) + e(t), from the data's projections, without iterations (D is 0 unless `'Feedthrough'` is true). `ssest` starts there and refines the model by prediction error minimization, in observer canonical form. The states are a basis of the model's own choosing; the poles, the frequency response and the outputs do not depend on it.

# Syntax
sys = n4sid(data, nx)
    Nx states, by subspace identification.
sys = n4sid(data, nx, 'Feedthrough', true)
    With a direct term.
sys = ssest(data, nx)
    Refined by prediction errors.
# Examples
## A resonance found again
> The data come from a system with poles at 0.9 e^(±0.3i).
u = idinput(600, 'rgs');
p = 0.9*exp(0.3i*[1 -1]);
y = filter([0 1 0.5], real(poly(p)), u) + 0.02*randn(600, 1);
data = iddata(y, u, 1);
s1 = n4sid(data, 2);
abs(eig(s1.A))', abs(angle(eig(s1.A)))'
s2 = ssest(data, 2);
abs(eig(s2.A))'
bode(s2)
# See also
arx tfest compare

@ tfest
A continuous-time transfer function fitted to sampled data.

np poles and nz zeros (np - 1 unless given), the input held between samples as sampled data are taken; the result is a continuous `tf`, for `step`, `bode` and the rest.

# Syntax
sys = tfest(data, np)
    Np poles.
sys = tfest(data, np, nz)
    And nz zeros.
# Examples
## A first-order process from its sampled response
> The data come from 2/(5s + 1), sampled every 0.5 seconds.
Ts = 0.5;
u = idinput(400, 'prbs', [0 0.2]);
G = c2d(tf(2, [5 1]), Ts);
y = lsim(G, u, (0:399)'*Ts) + 0.01*randn(400, 1);
m = tfest(iddata(y, u, Ts), 1, 0)
dcgain(m)

tf n4sid c2d

@ compare, sim
Models' outputs set against measured data, and a model's simulated response.

`compare` simulates each model with the data's input (or predicts K steps ahead) and draws its output over the measured one, the legend naming each model after its variable with the fit 100 (1 - |y - ŷ| / |y - mean(y)|) per cent: 100 is a perfect match, 0 no better than the mean. The initial state is estimated for simulations. `sim` gives a model's output for an input or a data set's input.

# Syntax
compare(data, sys1, sys2, ...)
    Drawn, with the fits.
compare(data, sys, K)
    K-step-ahead predictions.
[y, fit] = compare(data, sys1, ...)
    The outputs and the fits.
y = sim(sys, u)
    A simulated response.
# Examples
## Two orders judged on fresh data
u = idinput(600, 'prbs', [0 0.3]);
y = filter([0 0.2 0.15], [1 -1.5 0.7], u) + 0.05*randn(600, 1);
est = iddata(y(1:300), u(1:300), 1);
val = iddata(y(301:end), u(301:end), 1);
m1 = arx(est, [1 1 1]);
m2 = arx(est, [2 2 1]);
compare(val, m1, m2)
[~, fit] = compare(val, m1, m2);
round(fit, 1)
ys = sim(m2, ones(8, 1));
ys'

pe resid arx

@ pe, resid
Prediction errors of a model, and the analysis of its residuals.

`pe` gives the one-step (or K-step) prediction errors on a data set, as a data set (`e.y` the errors). `resid` draws the residuals' autocorrelation and their cross-correlation with the input, with 99% bounds: for a good model both stay within them, the residuals being white and owing nothing to the input. Its outputs give the residuals and the correlations.

# Syntax
e = pe(sys, data)
    One-step prediction errors.
e = pe(sys, data, K)
    K-step.
resid(data, sys)
    The residuals' correlations, drawn.
[E, R] = resid(data, sys)
    The residuals and the correlations.
# Examples
## A model too small, and one right
> The first model leaves the second pole unexplained: its residuals are correlated.
u = idinput(500, 'prbs', [0 0.4]);
y = filter([0 0.3 0.2], [1 -1.3 0.6], u) + filter(1, [1 -1.3 0.6], 0.05*randn(500, 1));
data = iddata(y, u, 1);
small = arx(data, [1 1 1]);
right = arx(data, [2 2 1]);
e1 = pe(small, data);
e2 = pe(right, data);
[std(e1.y), std(e2.y)]
resid(data, right)

@ polydata, present
A polynomial model's polynomials with their uncertainties, and a model shown with them.

`polydata` gives A, B, C, D and F (those the model does not have are 1, or 0 for B without an input), and the standard deviations of their coefficients. `present` shows the model with each coefficient's standard deviation.

# Syntax
[A, B, C, D, F, dA, dB, dC, dD, dF] = polydata(sys)
    The polynomials and their uncertainties.
present(sys)
    The model with its uncertainties.
# Examples
## How well each coefficient is known
u = idinput(300, 'prbs');
y = filter([0 0.8], [1 -0.6], u) + 0.1*randn(300, 1);
m = arx(iddata(y, u, 1), [1 1 1]);
[A, B, ~, ~, ~, dA, dB] = polydata(m);
[A; dA]
[B; dB]
present(m)

arx armax

@ aic, fpe
Information criteria and final prediction errors, to choose among models.

`aic` gives the Akaike information criterion, N log(V) + 2 n (plus terms that do not change between models of the same data), where V is the loss and n the number of parameters: smaller is better, the second term charging for each parameter. `'AICc'` corrects it for few samples, `'nAIC'` normalizes it, and `'BIC'` charges log(N) a parameter instead. `fpe` gives Akaike's final prediction error, V (1 + n/N)/(1 - n/N).

# Syntax
value = aic(sys1, sys2, ...)
    The criterion of each.
value = aic(sys, type)
    'AICc', 'nAIC' or 'BIC'.
value = fpe(sys1, sys2, ...)
    The final prediction errors.
# Examples
## The order the criteria choose
u = idinput(500, 'rgs');
y = filter([0 0.5 0.3], [1 -1.2 0.5], u) + filter(1, [1 -1.2 0.5], 0.1*randn(500, 1));
data = iddata(y, u, 1);
models = arrayfun(@(n) arx(data, [n n 1]), 1:5, 'UniformOutput', false);
a = cellfun(@aic, models)
f = cellfun(@fpe, models);
[~, best] = min(a)
