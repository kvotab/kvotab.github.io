@ datastore
A datastore: a collection of files read a block at a time, of the kind their extensions call for.

The location is a file, a folder, wildcards (`'data/*.csv'`) or a list of them; text files become a `tabularTextDatastore`, spreadsheets a `spreadsheetDatastore`, images an `imageDatastore`, Parquet files a `parquetDatastore`, and MAT-files of keys and values (as `mapreduce` writes them) a key-value datastore; `'Type'` says which when the extensions do not. A datastore is a handle: `read` gives the next block and moves on, `hasdata` says whether there is more, `reset` goes back to the start, `readall` reads everything. Data too large to read at once is read this way, block by block, or through `tall` arrays and `mapreduce`.

# Syntax
ds = datastore(location)
    A datastore of the files.
ds = datastore(location, 'Type', type)
    Of a kind: 'tabulartext', 'spreadsheet', 'image', 'file', 'parquet' or 'keyvalue'.
ds = datastore(location, 'IncludeSubfolders', true, 'FileExtensions', {'.csv', '.txt'})
    Through subfolders, of some extensions.
# Examples
## Three daily files read one at a time
mkdir logs
for d = 1:3
    T = table((1:4)', d*10 + (1:4)', 'VariableNames', {'hour', 'load'});
    writetable(T, sprintf('logs/day%d.csv', d));
end
ds = datastore('logs/*.csv');
class(ds)
ds.ReadSize = 'file';
total = 0;
while hasdata(ds)
    T = read(ds);
    total = total + sum(T.load);
end
total

@ tabularTextDatastore, spreadsheetDatastore, parquetDatastore
Datastores of tables: delimited text files, spreadsheets and Parquet files.

Each file is read as `readtable` (or `parquetread`) reads it, `ReadSize` rows at a time (20000 for text, a file for spreadsheets), or a whole `'file'` (or `'sheet'`). The variable names come from the first file; `SelectedVariableNames` reads only some, and options set the delimiter, header lines and text type as `readtable`'s do. A text datastore can give timetables (`'OutputType', 'timetable'`).

# Syntax
ds = tabularTextDatastore(location, 'Delimiter', d, 'NumHeaderLines', n, 'TextType', 'string')
    Delimited text.
ds = tabularTextDatastore(location, 'SelectedVariableNames', names, 'ReadSize', n)
    Some variables, n rows at a time.
ds = spreadsheetDatastore(location, 'Sheets', sheets, 'ReadSize', 'sheet')
    Spreadsheets.
pds = parquetDatastore(location, 'SelectedVariableNames', names, 'ReadSize', n)
    Parquet files.
# Examples
## Some variables, a few rows at a time
T = table((1:10)', rand(10, 1), randi(5, 10, 1), 'VariableNames', {'id', 'x', 'grp'});
writetable(T, 'measure.csv');
ds = tabularTextDatastore('measure.csv', 'SelectedVariableNames', {'id', 'grp'}, 'ReadSize', 4);
B = read(ds)
height(read(ds))
height(read(ds))
hasdata(ds)

@ imageDatastore, readimage, countEachLabel, splitEachLabel
A datastore of images: labelled, read one by one or by number, counted and split.

Images are read one at a time (or `ReadSize` at a time, in a cell; `readall` gives a cell of all); `readimage` reads the k-th without moving the datastore. `'LabelSource', 'foldernames'` labels each image by its folder, as a categorical in `Labels`. `countEachLabel` gives a table of each label and how many images it has; `splitEachLabel` splits the datastore label by label, a proportion (or a number) of each label's images to each output and the rest to the last, in order unless `'randomized'`.

# Syntax
imds = imageDatastore(location, 'IncludeSubfolders', true, 'LabelSource', 'foldernames')
    Images labelled by their folders.
imds = imageDatastore(location, 'Labels', labels, 'ReadSize', n, 'ReadFcn', @f)
    Labels, a read size, a function of one's own.
[img, info] = readimage(imds, k)
    The k-th image, with its file and label.
tbl = countEachLabel(imds)
    Images per label.
[ds1, ds2] = splitEachLabel(imds, p)
    Split, label by label.
[ds1, ds2, ds3] = splitEachLabel(imds, p1, p2, 'randomized')
    In three, at random.
# Examples
## Light and dark squares, labelled by folder
mkdir shapes/light
mkdir shapes/dark
for k = 1:6
    imwrite(uint8(200 + randi(55, 8)), sprintf('shapes/light/l%d.png', k));
end
for k = 1:4
    imwrite(uint8(randi(55, 8)), sprintf('shapes/dark/d%d.png', k));
end
imds = imageDatastore('shapes', 'IncludeSubfolders', true, 'LabelSource', 'foldernames');
countEachLabel(imds)
[train, test] = splitEachLabel(imds, 0.5);
[numel(train.Files) numel(test.Files)]
[img, info] = readimage(imds, 7);
[size(img), mean(img(:)) > 128]
info.Label

@ fileDatastore, arrayDatastore
Datastores of any files, each read by a function, and of an array in memory.

A `fileDatastore` reads each file by `ReadFcn` (a file name in, its data out); `'partialfile'` reads a file in pieces through [data, state, done] = f(filename, state), and `'bytes'` reads `BlockSize` bytes at a time. `readall` gives a cell, or the data joined when `UniformRead` is true. An `arrayDatastore` reads an array `ReadSize` slices at a time along `IterationDimension` (1): in a cell, or with `'OutputType', 'same'` as an array.

# Syntax
fds = fileDatastore(location, 'ReadFcn', @load)
    Files read by a function.
fds = fileDatastore(location, 'ReadFcn', @f, 'UniformRead', true)
    Their data joined by readall.
ads = arrayDatastore(A, 'ReadSize', n, 'IterationDimension', d, 'OutputType', 'same')
    An array, n slices at a time.
# Examples
## MAT-files read by load, and rows of a matrix
for k = 1:3
    v = k*ones(1, 2);
    save(sprintf('part%d.mat', k), 'v');
end
fds = fileDatastore('part*.mat', 'ReadFcn', @(f) getfield(load(f), 'v'), 'UniformRead', true);
readall(fds)
ads = arrayDatastore(magic(4), 'ReadSize', 2, 'OutputType', 'same');
read(ads)
read(ads)

@ readall, hasdata, preview, progress
Everything a datastore holds; whether it has more; its first block; how far it has read.

`readall` reads everything from the start (tables joined one under another, images and other files in a cell), without moving the datastore. `hasdata` is true while there is more to `read`; `preview` gives the first block (eight rows of a table) without moving it; `progress` is the share read so far, from 0 to 1.

# Syntax
data = readall(ds)
    Everything.
tf = hasdata(ds)
    More to read.
data = preview(ds)
    The first block.
p = progress(ds)
    The share read.
# Examples
## Reading through, and the whole at once
writematrix((1:12)', 'nums.csv');
ds = tabularTextDatastore('nums.csv', 'ReadVariableNames', false, 'ReadSize', 4);
height(preview(ds))
while hasdata(ds)
    b = read(ds);
    fprintf('%d rows, %.0f%% read\n', height(b), 100*progress(ds));
end
A = readall(ds);
sum(A.Var1)

@ numpartitions, partition, isPartitionable, shuffle, isShuffleable, subset
Datastores split into parts, put in random order, and narrowed to some files.

A datastore splits into parts by its files (by slices for an `arrayDatastore`): `numpartitions` says into how many (no more than a pool's workers when one is given), and `partition` gives the k-th of n parts, or the part of one file, for one worker of `parfor` each. `shuffle` puts the files (or slices) in random order, `subset` keeps some of them; `isPartitionable` and `isShuffleable` say whether a datastore can.

# Syntax
n = numpartitions(ds)
    How many parts.
subds = partition(ds, n, k)
    The k-th of n parts.
subds = partition(ds, 'Files', k)
    The part of one file.
dsnew = shuffle(ds)
    In random order.
dsnew = subset(ds, indices)
    Some of the files or slices.
tf = isPartitionable(ds)
    True when it can be partitioned.
tf = isShuffleable(ds)
    True when it can be shuffled.
# Examples
## A datastore of six rows, in parts
ads = arrayDatastore((1:6)');
numpartitions(ads)
p = partition(ads, 2, 1);
readall(p)
[isPartitionable(ads), isShuffleable(ads)]
readall(subset(ads, [6 1]))

@ transform, writeall
Datastores whose reads go through a function, and datastores written out again.

`transform` gives a datastore whose `read` gives what a function makes of the original's read (one input for each datastore given; with `'IncludeInfo'` the function takes and gives the info too). `writeall` reads each file and writes it to a folder again (tables by `writetable`, images by `imwrite`, other data to MAT-files), the folders under the files' common folder kept unless `'FolderLayout'` is `'flatten'`, with a prefix or suffix to the names.

# Syntax
dsnew = transform(ds, @fcn)
    Reads through a function.
dsnew = transform(ds1, ds2, @fcn)
    Of two datastores read together.
writeall(ds, folder, 'OutputFormat', fmt, 'FilenamePrefix', p, 'FilenameSuffix', s)
    Written to a folder.
# Examples
## Tables cleaned on the way in, and written out
mkdir raw
writetable(table([1; NaN; 3], 'VariableNames', {'v'}), 'raw/a.csv');
writetable(table([NaN; 5], 'VariableNames', {'v'}), 'raw/b.csv');
ds = tabularTextDatastore('raw');
clean = transform(ds, @rmmissing);
readall(clean)
writeall(ds, 'copy', 'FilenamePrefix', 'new_');
dir('copy')

@ mapreduce, add, addmulti, hasnext, getnext
Map and reduce functions run over a datastore.

`mapreduce` reads the datastore block by block and calls the map function on each, `mapfun(data, info, intermKVStore)`, which adds keys and values with `add` (one) or `addmulti` (several). Then it calls the reduce function once for each key, `reducefun(key, valueIterator, outKVStore)`, which reads that key's values with `hasnext` and `getnext` and adds its results. The result is a key-value datastore: `readall` gives a table of Key and Value. With `'OutputFolder'` the results are saved there too.

# Syntax
outds = mapreduce(ds, @mapfun, @reducefun)
    The results as a datastore.
outds = mapreduce(ds, @mapfun, @reducefun, 'OutputFolder', folder, 'Display', 'off')
    Saved to a folder, quietly.
add(store, key, value)
    A key and value added.
addmulti(store, keys, values)
    Several.
tf = hasnext(valueIterator)
    More values.
value = getnext(valueIterator)
    The next value.
# Examples
## Totals by group, in two passes
> The map function totals each block by group; the reduce function adds up each group's totals.
T = table(randi(3, 60, 1), ones(60, 1), 'VariableNames', {'grp', 'n'});
writetable(T, 'counts.csv');
lines = {
    'function mapper(data, ~, store)'
    '[g, ~, k] = unique(data.grp);'
    'addmulti(store, num2cell(g), num2cell(accumarray(k, data.n)));'
    'end'};
fid = fopen('mapper.m', 'w'); fprintf(fid, '%s\n', lines{:}); fclose(fid);
lines = {
    'function reducer(key, it, store)'
    's = 0;'
    'while hasnext(it), s = s + getnext(it); end'
    'add(store, key, s);'
    'end'};
fid = fopen('reducer.m', 'w'); fprintf(fid, '%s\n', lines{:}); fclose(fid);
ds = tabularTextDatastore('counts.csv', 'ReadSize', 20);
out = mapreduce(ds, @mapper, @reducer, 'Display', 'off');
R = readall(out);
R = sortrows(R, 'Key')
groupcounts(T.grp)'

@ tall, gather, istall, classUnderlying, isaUnderlying
Tall arrays: computations on data too large for memory, done when gathered.

`tall` makes a tall array of an array or of a datastore. Operators, indexing (`t(k)`, `t.Var`, `t{:, 'x'}`) and the common functions of numbers, tables, text, dates and categories give tall arrays that remember what to compute; `gather` computes it, each step once, reading a datastore block by block. A value that is not tall is given back as it is. `istall` says whether a value is tall; `classUnderlying` gives the class of its values and `isaUnderlying` tests it (also for `'numeric'`, `'float'` or `'integer'`). Plots of tall arrays gather them first.

# Syntax
t = tall(A)
    A tall array of an array.
t = tall(ds)
    Of a datastore.
A = gather(t)
    The values computed.
[A, B] = gather(t1, t2)
    Several at once.
tf = istall(A)
    True for a tall array.
c = classUnderlying(t)
    The class of its values.
tf = isaUnderlying(t, classname)
    True when its values are of a class.
# Examples
## A mean over files, computed when gathered
mkdir parts
for k = 1:4
    writetable(table(k*(1:5)', 'VariableNames', {'x'}), sprintf('parts/p%d.csv', k));
end
t = tall(tabularTextDatastore('parts'));
m = mean(t.x)
istall(m)
gather(m)
[classUnderlying(t.x), string(isaUnderlying(t.x, 'float'))]
[lo, hi] = gather(min(t.x), max(t.x))
