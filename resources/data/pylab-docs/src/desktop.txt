@ commandwindow, commandhistory, workspace, filebrowser
The desktop's windows brought forward: the Command Window, the Command History, the Workspace and the Current Folder.

Each shows its window (as a tab of its group when the windows are docked) and `commandwindow` also gives it the keyboard, so a program can hand back to the person at the Command Window when it has finished.

# Syntax
commandwindow
    The Command Window, with the keyboard.
commandhistory
    The Command History.
workspace
    The Workspace.
filebrowser
    The Current Folder.
# Examples
## A program that ends by showing its results
results = magic(4);
workspace
commandwindow
size(results)

@ openvar
A variable opened in the Variables view, to look at and edit as a table.

The name is a variable's, or a part of one such as `'s.data'` or `'c{2}'`.

# Syntax
openvar(name)
    The variable, or part, opened.
# Examples
## A matrix and a field
s.data = rand(4, 3);
openvar('s.data')

@ matlabRelease
Which release is running.

PyLAB answers with its own name: `Release` is `"PyLAB"`, `Stage` `"release"`, `Update` 0 and the date not known.

# Syntax
r = matlabRelease
    The release.
# Examples
## The release
r = matlabRelease;
r.Release

@ maxNumCompThreads
How many threads computations use.

In the page Python runs in one thread; the number can be set (and the old one is given back), so programs that set it run unchanged.

# Syntax
n = maxNumCompThreads
    The number.
old = maxNumCompThreads(n)
    Set, the old number given back.
old = maxNumCompThreads('automatic')
    Back to the automatic number.
# Examples
## Set and put back
old = maxNumCompThreads(2);
maxNumCompThreads
maxNumCompThreads(old);

@ memory
The memory the engine uses and can have.

In the page this is the WebAssembly memory of its Python, which grows as needed up to 4 GB. With outputs, `userview` has the memory used by this engine and the largest array it can make, `systemview` the memory of the browser's process.

# Syntax
memory
    Shown.
[userview, systemview] = memory
    As structs.
# Examples
## The fields of the answer
> The numbers depend on the computer and on what has been done, so only the fields are shown.
[u, s] = memory;
fieldnames(u)

@ license
Whether the engine has a toolbox's functions.

`license('test', feature)` is true for the toolboxes PyLAB has functions of; feature names are toolboxes' names such as `'Statistics_Toolbox'`, `'Optimization_Toolbox'` or `'Signal_Toolbox'`, in any case. `'checkout'` answers the same with a message, and `'inuse'` lists them.

# Syntax
tf = license('test', feature)
    Whether it is there.
[tf, msg] = license('checkout', feature)
    With a message.
license('inuse')
    The list.
# Examples
## A program checking before it uses a toolbox
if license('test', 'statistics_toolbox')
    disp('fitting with the statistics functions')
end
