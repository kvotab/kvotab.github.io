@ awgn
A signal with white Gaussian noise added, at a signal-to-noise ratio.

The noise's power is the signal's power divided by the ratio: snr in dB (or `'linear'`), the signal's power in dBW (0, that is 1 W, unless given) or `'measured'` from x itself. A complex signal gets complex noise, half its power in each part. A seed draws the noise from a generator of its own, so that the same call gives the same noise.

# Syntax
y = awgn(x, snr)
    Noise at snr dB, the signal taken as 1 W.
y = awgn(x, snr, 'measured')
    The signal's power measured.
y = awgn(x, snr, sigpower)
    The signal's power given, in dBW.
y = awgn(x, snr, sigpower, seed)
    The noise from a seed.
y = awgn(x, snr, sigpower, 'linear')
    snr and sigpower as ratios, not dB.
# Examples
## A sine at 10 dB, and the ratio measured back
t = (0:9999)'/1000;
x = sin(2*pi*5*t);
y = awgn(x, 10, 'measured');
10*log10(mean(x.^2)/mean((y - x).^2))
plot(t(1:500), y(1:500), t(1:500), x(1:500))

randn snr berawgn

@ qammod, qamdemod
Quadrature amplitude modulation: integers or bits to points in the complex plane, and back.

Square M-QAM (M = 2 or a power of 4) places the integers 0 to M-1 on a square grid of odd levels, ±1, ±3, ...: half of each integer's bits pick the in-phase level and half the quadrature level, each Gray coded so that neighbours differ in one bit, unless `symOrder` is `'bin'` or a mapping. `'InputType', 'bit'` takes groups of log2(M) bits, the first the most significant; `'UnitAveragePower'` scales the points to an average power of 1. `qamdemod` gives the nearest point's integer, its bits, or each bit's log-likelihood ratio (`'llr'`, with the noise's variance).

# Syntax
y = qammod(x, M)
    Integers to points.
y = qammod(x, M, symOrder, 'InputType', 'bit', 'UnitAveragePower', true)
    Bits to points of unit average power.
z = qamdemod(y, M)
    Points to the nearest integers.
z = qamdemod(y, M, symOrder, 'OutputType', 'bit')
    Points to bits.
z = qamdemod(y, M, 'OutputType', 'llr', 'NoiseVariance', v)
    Each bit's log-likelihood ratio.
# Examples
## 16-QAM through noise
x = randi([0 15], 2000, 1);
s = qammod(x, 16, 'UnitAveragePower', true);
r = awgn(s, 15, 'measured');
z = qamdemod(r, 16, 'UnitAveragePower', true);
symerr(x, z)
scatterplot(r)
## The constellation's labels
> Gray coding: along the top row of 16-QAM, each point's label differs from the next in one bit.
qammod((0:3)', 4)
dec2bin(qamdemod([-3+3i; -1+3i; 1+3i; 3+3i], 16), 4)
# See also
pskmod scatterplot berawgn int2bit

@ pskmod, pskdemod
Phase shift keying: integers or bits to points on the unit circle, and back.

The integer at position p (Gray coded from the integer unless `symOrder` is `'bin'`) becomes exp(1i (2 pi p/M + phaseoffset)). `pskdemod` gives the integer (or bits) whose point is nearest in phase.

# Syntax
y = pskmod(x, M)
    Integers to points.
y = pskmod(x, M, phaseoffset, symOrder, 'InputType', 'bit')
    With a phase offset and order; from bits.
z = pskdemod(y, M, phaseoffset, symOrder, 'OutputType', 'bit')
    Points to integers or bits.
# Examples
## QPSK at pi/4, and 8-PSK's errors at 12 dB
y = pskmod((0:3)', 4, pi/4)
x = randi([0 7], 5000, 1);
r = awgn(pskmod(x, 8), 12);
[n, rate] = symerr(x, pskdemod(r, 8))
# See also
qammod pammod berawgn

@ pammod, pamdemod
Pulse amplitude modulation: integers or bits to real levels, and back.

The levels are -(M-1), -(M-3), ..., M-1, Gray coded unless `'bin'`, turned by a phase offset if given. `pamdemod` gives the integer (or bits) of the nearest level.

# Syntax
y = pammod(x, M, phaseoffset, symOrder, 'InputType', 'bit')
    Integers or bits to levels.
z = pamdemod(y, M, phaseoffset, symOrder, 'OutputType', 'bit')
    Levels to integers or bits.
# Examples
## Four levels, Gray and binary
[pammod((0:3)', 4), pammod((0:3)', 4, 0, 'bin')]
pamdemod([-2.6 0.4 3.3], 4)
# See also
qammod pskmod

@ int2bit, bit2int, de2bi, bi2de
Integers as bits and bits as integers.

`int2bit` writes each integer as n bits down its column (a column of n bits for each element), the most significant first unless `msbfirst` is false; `bit2int` reads each n bits back. `de2bi` and `bi2de` are the older forms, a row of digits for each number (base 2 unless given), the least significant digit first unless `'left-msb'`.

# Syntax
Y = int2bit(X, n)
    n bits down each column.
Y = int2bit(X, n, msbfirst)
    The order of the bits.
Y = bit2int(X, n)
    Each n bits as an integer.
B = de2bi(D, n, p, 'left-msb')
    A row of digits for each number.
D = bi2de(B, p, 'left-msb')
    Rows of digits as numbers.
# Examples
## The same numbers four ways
b = int2bit([5 12], 4)
bit2int(b, 4)
de2bi([5; 12], 4)
de2bi([5; 12], 4, 'left-msb')
bi2de([1 0 1 0; 0 0 1 1])
# See also
dec2bin qammod

@ bin2gray, gray2bin
Integers as Gray-coded labels of a modulation's points, and back.

For `'pam'`, `'psk'` and `'fsk'` the binary-reflected Gray code, in which neighbours differ in one bit; for `'qam'` each axis's half of the bits coded apart, so that neighbours in the grid differ in one bit. The second output is the mapping, the Gray label of each integer.

# Syntax
[y, map] = bin2gray(x, modulation, M)
    Gray labels.
[y, map] = gray2bin(x, modulation, M)
    Back to integers.
# Examples
## Eight labels
[g, map] = bin2gray(0:7, 'psk', 8);
map'
dec2bin(map, 3)
gray2bin(g, 'psk', 8)
# See also
pskmod qammod

@ biterr, symerr
Bit errors and symbol errors between two sets of integers.

`biterr` counts the bits that differ (k bits to each value, as many as the largest needs unless given), with the rate and each element's count; `symerr` counts the elements that differ, with the rate and where they are.

# Syntax
[number, ratio, individual] = biterr(x, y, k)
    Bit errors.
[number, ratio, loc] = symerr(x, y)
    Symbol errors.
# Examples
## One symbol, two bits
x = [0 3 5 7];
y = [0 3 6 7];
[nb, rb] = biterr(x, y, 3)
[ns, rs, loc] = symerr(x, y)
# See also
berawgn qamdemod

@ berawgn
Bit and symbol error rates of modulations in white Gaussian noise, worked out exactly.

Eb/N0 in dB, the energy per bit over the noise's density; Gray coding. PSK, PAM and square QAM are exact (QAM as two PAMs; PSK from the density of the received phase); differential PSK, FSK and MSK too. A simulation's error rate approaches these as its symbols grow many.

# Syntax
[ber, ser] = berawgn(EbNo, 'psk', M, 'nondiff')
    PSK.
[ber, ser] = berawgn(EbNo, 'qam', M)
    Square QAM.
[ber, ser] = berawgn(EbNo, 'pam', M)
    PAM.
ber = berawgn(EbNo, 'dpsk', 2)
    Differential PSK.
ber = berawgn(EbNo, 'fsk', 2, 'coherent')
    FSK.
ber = berawgn(EbNo, 'msk')
    MSK.
# Examples
## Error rates against Eb/N0
EbNo = 0:12;
semilogy(EbNo, berawgn(EbNo, 'psk', 2, 'nondiff'), EbNo, berawgn(EbNo, 'psk', 8, 'nondiff'), EbNo, berawgn(EbNo, 'qam', 16), EbNo, berawgn(EbNo, 'qam', 64))
legend('BPSK', '8-PSK', '16-QAM', '64-QAM', 'Location', 'southwest'), grid on
xlabel('E_b/N_0 (dB)'), ylabel('bit error rate'), ylim([1e-7 1])
berawgn(10, 'psk', 2, 'nondiff')

@ rcosdesign
A raised-cosine filter, to shape symbols into pulses that do not disturb each other.

The filter spans `span` symbols at `sps` samples each (span sps + 1 taps), with roll-off beta (0 to 1, the excess bandwidth); `'sqrt'` (the default) is the root raised cosine, used at both ends so that together they make a raised cosine, and `'normal'` the raised cosine itself, which is zero at every other symbol's time. The taps have unit energy.

# Syntax
b = rcosdesign(beta, span, sps)
    A root raised cosine.
b = rcosdesign(beta, span, sps, shape)
    'sqrt' or 'normal'.
# Examples
## A raised cosine, zero at the other symbols' times
b = rcosdesign(0.35, 6, 8, 'normal');
numel(b)
stem(-24:24, b), xlabel('samples (8 a symbol)')
round(b(1:8:end), 6)
# See also
upfirdn eyediagram filter

@ eyediagram, scatterplot
An eye diagram, and a constellation diagram.

`eyediagram` draws the signal in traces of n + 1 samples (two symbol periods at n samples a symbol) laid over each other, so that the eye's opening shows how well the symbols can be told apart; a complex signal draws its in-phase and quadrature parts apart. `scatterplot` draws every n-th sample (from offset) as a point, quadrature against in-phase.

# Syntax
eyediagram(x, n)
    Traces of n samples a symbol.
h = eyediagram(x, n, period, offset)
    Over -period/2 to period/2, from offset.
scatterplot(x)
    The constellation.
h = scatterplot(x, n, offset, plotstring)
    Every n-th sample, drawn as plotstring says.
# Examples
## Pulses shaped and their eye
> Root raised cosines at both ends make a raised cosine: at the symbol times the eye is open.
sps = 8;
b = rcosdesign(0.5, 6, sps);
x = 2*randi([0 1], 200, 1) - 1;
tx = upfirdn(x, b, sps);
rx = filter(b, 1, tx);
eyediagram(rx(97:end - 96), 2*sps)
## A noisy QPSK constellation
s = pskmod(randi([0 3], 1000, 1), 4, pi/4);
scatterplot(awgn(s, 18), 1, 0, 'b.')

rcosdesign qammod
