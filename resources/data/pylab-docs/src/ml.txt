@ fitctree, fitrtree
Decision trees for classification and regression.

A tree splits the data again and again on one predictor at a time, each split where the impurity falls most: the Gini index (or the deviance) for classes, the squared error for numbers. Splitting stops at `'MaxNumSplits'`, or when a node has fewer than `'MinParentSize'` observations or a child would have fewer than `'MinLeafSize'`. A classification leaf predicts its most frequent class, a regression leaf its mean. Every model of this family keeps its data and takes `predict`, `loss`, `resubLoss`, `resubPredict` and `crossval`; `view` prints a tree's rules. The fit functions also take `'ClassNames'`, `'Prior'`, `'Weights'`, predictor and response names, and the cross-validation options, which give a cross-validated model.

# Syntax
Mdl = fitctree(X, Y, 'MaxNumSplits', n, 'MinLeafSize', m, 'SplitCriterion', c)
    A classification tree.
Mdl = fitctree(Tbl, ResponseVarName)
    From a table.
Mdl = fitrtree(X, Y, 'MinLeafSize', m)
    A regression tree.
# Examples
## Two classes divided by a step
X = rand(200, 2);
Y = categorical(X(:, 1) > 0.6 & X(:, 2) > 0.3, [false true], {'out', 'in'});
t = fitctree(X, Y, 'MaxNumSplits', 3);
view(t)
predict(t, [0.8 0.5; 0.2 0.9])
resubLoss(t)
## A curve by steps
x = linspace(0, 2*pi, 200)';
y = sin(x) + 0.1*randn(200, 1);
r = fitrtree(x, y, 'MinLeafSize', 15);
plot(x, y, '.', x, predict(r, x), 'LineWidth', 1.5)
round(resubLoss(r), 4)

@ fitcknn
A k-nearest-neighbour classifier.

A point is given the class most common among its k nearest training points (1 unless `'NumNeighbors'` says), by a distance (Euclidean unless named), the votes weighted equally or by inverse distance; the score of each class is its share. With `'Standardize'` the predictors are put on one scale first.

# Syntax
Mdl = fitcknn(X, Y)
    The nearest point decides.
Mdl = fitcknn(X, Y, 'NumNeighbors', k, 'Distance', d, 'DistanceWeight', w, 'Standardize', tf)
    k neighbours, weighted.
# Examples
## Five neighbours vote
X = [randn(50, 2); randn(50, 2) + 2.5];
Y = [ones(50, 1); 2*ones(50, 1)];
m = fitcknn(X, Y, 'NumNeighbors', 5);
[label, score] = predict(m, [0 0; 1.25 1.25; 3 3])

@ fitcdiscr, fitcnb

`fitcdiscr` takes each class as a multivariate normal distribution: with one covariance pooled over the classes (`'linear'`, straight boundaries) or each its own (`'quadratic'`, curved ones), or their diagonals, or pseudo-inverses when singular; the score is the posterior probability. `fitcnb` takes each predictor as independent within a class: normal (unless named), a kernel density, or frequencies of values or counts.

# Syntax

@ fitcsvm, fitrsvm
Support vector machines: a widest margin between two classes, and regression within a tube.

`fitcsvm` finds the boundary with the widest margin between two classes, allowing misclassified points at a cost (`'BoxConstraint'`), in the space of a kernel: linear, Gaussian (`'rbf'`) or polynomial, scaled by `'KernelScale'` (`'auto'` picks one). Its score is the signed distance from the boundary. `fitrsvm` fits a function that keeps the data within epsilon of it where it can. Standardizing the predictors usually helps.

# Syntax
Mdl = fitcsvm(X, Y, 'KernelFunction', k, 'BoxConstraint', C, 'KernelScale', s, 'Standardize', tf)
    A classifier.
Mdl = fitrsvm(X, Y, 'KernelFunction', k, 'Epsilon', e, 'Standardize', tf)
    Regression.
# Examples
## A ring around a core
t = 2*pi*rand(150, 1);
X = [0.5*randn(150, 2); [2.5*cos(t), 2.5*sin(t)] + 0.3*randn(150, 2)];
Y = [-ones(150, 1); ones(150, 1)];
m = fitcsvm(X, Y, 'KernelFunction', 'gaussian', 'KernelScale', 'auto', 'Standardize', true);
resubLoss(m)
predict(m, [0 0; 2.5 0])
[x1, x2] = meshgrid(linspace(-4, 4, 100));
[~, s] = predict(m, [x1(:) x2(:)]);
contour(x1, x2, reshape(s(:, 2), size(x1)), [0 0], 'k', 'LineWidth', 1.5), hold on, gscatter(X(:, 1), X(:, 2), Y), hold off
## A noisy line fitted within a tube
x = (1:50)';
y = 2*x + 5 + 3*randn(50, 1);
r = fitrsvm(x, y, 'KernelFunction', 'linear');
round(predict(r, [10; 40])')

@ fitcecoc, templateTree, templateSVM, templateKNN, templateDiscriminant, templateNaiveBayes, templateLinear, templateKernel, templateGP
Many classes by binary learners, and the templates that set the learners' options.

`fitcecoc` turns a problem of many classes into binary ones by a coding: one class against another for each pair (`'onevsone'`, the default) or each against all the rest; each binary learner is an SVM unless named (`'tree'`, `'knn'`, `'discriminant'`, `'naivebayes'`, `'linear'`) or given as a template. A class's score is minus the mean loss of the learners over it. The templates hold a learner's options for `fitcecoc` and the ensembles: `templateTree`, `templateSVM`, `templateKNN`, `templateDiscriminant`, `templateNaiveBayes`, `templateLinear`, `templateKernel` and `templateGP`.

# Syntax
Mdl = fitcecoc(X, Y, 'Learners', t, 'Coding', c)
    Many classes.
t = templateSVM('KernelFunction', k, ...)
    An SVM's options.
t = templateTree('MaxNumSplits', n, ...)
    A tree's.
t = templateKNN('NumNeighbors', k)
    k-nearest neighbours'.
t = templateDiscriminant('DiscrimType', type)
    Discriminant analysis'.
t = templateNaiveBayes(...)
    Naive Bayes'.
t = templateLinear('Learner', l, 'Lambda', lambda)
    A linear learner's.
t = templateKernel('KernelScale', s)
    A kernel learner's.
t = templateGP('KernelFunction', k)
    A Gaussian process's.
# Examples
## Four classes, two kinds of learner
c = [0 0; 3 0; 0 3; 3 3];
X = [randn(40, 2) + c(1, :); randn(40, 2) + c(2, :); randn(40, 2) + c(3, :); randn(40, 2) + c(4, :)];
Y = repelem((1:4)', 40);
m1 = fitcecoc(X, Y);
m2 = fitcecoc(X, Y, 'Learners', templateTree('MaxNumSplits', 4), 'Coding', 'onevsall');
size(m1.CodingMatrix), size(m2.CodingMatrix)

@ fitcensemble, fitrensemble, TreeBagger, oobLoss, oobPredict
Ensembles of trees: boosted and bagged.

Many small trees together predict better than one. Boosting (`'AdaBoostM1'` for two classes, `'AdaBoostM2'` for more, `'GentleBoost'`, `'LogitBoost'`, `'LSBoost'` for regression) grows each tree on what the earlier ones got wrong; bagging (`'Bag'`, a random forest) grows full trees on bootstrap samples, a random few predictors tried at each split, and averages them. A bagged ensemble's out-of-bag loss (`oobLoss`) and predictions (`oobPredict`) use, for each observation, only the trees that did not see it: an honest estimate without a test set. `TreeBagger` is the older way to bag.

# Syntax
Mdl = fitcensemble(X, Y, 'Method', m, 'NumLearningCycles', n, 'Learners', t)
    Classification.
Mdl = fitrensemble(X, Y, 'Method', m, 'NumLearningCycles', n)
    Regression.
B = TreeBagger(n, X, Y, 'Method', 'classification')
    Bagged trees.
L = oobLoss(Mdl)
    The out-of-bag loss.
[label, score] = oobPredict(Mdl)
    The out-of-bag predictions.
# Examples
## A forest's honest error, and boosting's training error
X = rand(300, 4);
Y = categorical(X(:, 1) + X(:, 2).^2 + 0.2*randn(300, 1) > 0.9);
bag = fitcensemble(X, Y, 'Method', 'Bag', 'NumLearningCycles', 60);
round(oobLoss(bag), 3)
boost = fitcensemble(X, Y, 'Method', 'AdaBoostM1', 'NumLearningCycles', 60);
round(resubLoss(boost), 3)
r = fitrensemble(X, X(:, 1).^2 + X(:, 3), 'Method', 'LSBoost', 'NumLearningCycles', 80);
round(resubLoss(r), 4)

@ crossval, kfoldLoss, kfoldPredict
Cross-validation: a model judged on data it was not fitted to.

`crossval` fits the model again on each training set of a partition (10 folds unless `'KFold'`, `'Holdout'`, `'Leaveout'` or a `cvpartition` says) and gives a cross-validated model; `kfoldLoss` gives the loss of each fold's model on the observations it left out (their average, or each), and `kfoldPredict` each observation's prediction by the model that did not see it. Given a function instead, `crossval` gives its values for each fold, or the cross-validated mean squared error or misclassification rate of a prediction function.

# Syntax
CVMdl = crossval(Mdl, 'KFold', k)
    A cross-validated model.
L = kfoldLoss(CVMdl, 'Mode', m)
    The loss.
[label, score] = kfoldPredict(CVMdl)
    The predictions.
vals = crossval(fun, X, Y, 'KFold', k)
    A function's values for each fold.
mse = crossval('mse', X, y, 'Predfun', predfun)
    A prediction's error.
# Examples
## The size of tree that generalizes
X = randn(300, 2);
Y = double(X(:, 1).*X(:, 2) + 0.5*randn(300, 1) > 0);
splits = [1 4 16 64];
cvl = zeros(size(splits));
for k = 1:4
    cvl(k) = kfoldLoss(crossval(fitctree(X, Y, 'MaxNumSplits', splits(k)), 'KFold', 5));
end
round(cvl, 3)
## A prediction function's error
x = linspace(0, 1, 60)';
y = 3*x + 0.2*randn(60, 1);
predfun = @(xtr, ytr, xte) [ones(size(xte)) xte]*([ones(size(xtr)) xtr]\ytr);
round(crossval('mse', x, y, 'Predfun', predfun), 3)
