@ num2cell, cell2mat, mat2cell
Arrays into cell arrays and back: each element in a cell, cells joined into one array, and an array divided into blocks.

`num2cell(A)` puts each element in a cell of its own (or, with `dims`, each slice along those dimensions). `cell2mat` joins the contents of a cell array into one array; the cells must fit together as blocks. `mat2cell(A, rowSizes, colSizes)` divides an array into blocks of those sizes.

# Syntax
C = num2cell(A)
    A cell for each element.
C = num2cell(A, dims)
    A cell for each slice.
A = cell2mat(C)
    The contents joined.
C = mat2cell(A, rowSizes, colSizes)
    Blocks of those sizes.
# Examples
## There and back
C = num2cell([1 2 3])
cell2mat({[1 2], [3]; [4 5], [6]})
## Columns, and blocks
num2cell(magic(3), 1)
B = mat2cell(magic(4), [1 3], [2 2]);
size(B{2, 1})
# See also
cell cellfun

@ celldisp
Each element of a cell array shown with its index.

Nested cells are shown element by element, with indices like `C{2}{1}`. A name to show in place of the variable's may be given.

# Syntax
celldisp(C)
    The elements.
celldisp(C, name)
    Under another name.
# Examples
## A nested cell array
C = {1, 'text', {2, [3 4]}};
celldisp(C)
# See also
cell disp

@ cell2struct, struct2cell
A struct array from a cell array and field names, and the field values of a struct as a cell array.

`cell2struct(C, fields, dim)` makes a field from each element along dimension `dim` (rows with 1, columns with 2). `struct2cell` gives a cell for each field, one column per element of a struct array.

# Syntax
s = cell2struct(C, fields, dim)
    A struct array.
C = struct2cell(s)
    The values.
# Examples
## Fields from rows, and back
C = {'Ada', 1815; 'Alan', 1912};
s = cell2struct(C, {'name', 'born'}, 2);
s(2)
struct2cell(s(1))
# See also
struct fieldnames

@ rmfield, setfield, getfield, orderfields
A struct's fields removed, set, read and put in order, as functions.

`setfield(s, name, value)` and `getfield(s, name)` are `s.(name) = value` and `s.(name)`. `rmfield` removes one field or a list. `orderfields` sorts the fields alphabetically, or in the order of another struct, a cell of names or a permutation; `perm` gives the old positions.

# Syntax
s = rmfield(s, names)
    Without those fields.
s = setfield(s, name, value)
    A field set.
v = getfield(s, name)
    A field's value.
[s, perm] = orderfields(s1, order)
    In order.
# Examples
## A small record, edited
s = struct('zeta', 1, 'alpha', 2, 'mid', 3);
s = setfield(s, 'beta', 4);
getfield(s, 'alpha')
s = rmfield(s, 'mid');
[s, perm] = orderfields(s)
# See also
struct fieldnames isfield

@ structfun
A function called on every field of a scalar struct.

The results are collected in a column, one per field, when each is a single value; with `'UniformOutput', false`, as a struct with the same fields.

# Syntax
A = structfun(fun, s)
    A column of results.
B = structfun(fun, s, 'UniformOutput', false)
    A struct of results.
# Examples
## Means of each field, and the fields doubled
s = struct('a', [1 2 3], 'b', [10 20], 'c', 5);
structfun(@mean, s)
structfun(@(x) 2*x, s, 'UniformOutput', false)

@ dictionary
Keys and the values they stand for, in the order they were put in.

`d(keys)` looks keys up; `d(keys) = values` puts them in, giving a new dictionary (it is a value, not a handle: a copy is apart); `d(keys) = []` takes them out; `d{keys}` gives the contents of cell values. Keys are text (kept as strings), numbers or logical values; the values are all of one class. An empty `dictionary()` gets its types from what is first put in.

# Syntax
d = dictionary(keys, values)
    From arrays of keys and values.
d = dictionary(k1, v1, k2, v2, ...)
    From pairs.
d = dictionary()
    Empty, without types yet.
# Examples
## Prices by fruit
d = dictionary(["apple" "pear" "plum"], [3.5 4 6])
d("pear")
d("kiwi") = 5;
d(["apple" "kiwi"])
d("plum") = [];
keys(d)'
# See also
insert lookup containers.Map

@ insert, lookup, numEntries, isConfigured, types, entries
A dictionary's entries put in, looked up with a fallback, counted, and listed; and its types.

`insert` gives a dictionary with keys and values put in (`'Overwrite', false` keeps values already there). `lookup` gives the values of keys, or `FallbackValue` for keys it does not have instead of an error. `numEntries` counts the keys, `isConfigured` says whether the key and value types are set, `types` gives them, and `entries` lists the keys and values as a table (or a struct array, or a cell).

# Syntax
d = insert(d, keys, values)
    Entries put in.
v = lookup(d, keys, FallbackValue=x)
    Values, with a fallback.
n = numEntries(d)
    How many.
tf = isConfigured(d)
    Whether its types are set.
[keyType, valueType] = types(d)
    Its types.
T = entries(d)
    As a table.
# Examples
## An inventory
d = dictionary();
isConfigured(d)
d = insert(d, ["bolts" "nuts"], [120 300]);
[isConfigured(d) numEntries(d)]
[kt, vt] = types(d)
lookup(d, ["nuts" "screws"], FallbackValue=0)
entries(d)
# See also
dictionary

@ containers.Map
A map from keys (text or numbers) to values: a handle, so copies share it.

`M(key)` reads and sets values; `M.Count` is the number of keys; `keys`, `values`, `isKey` and `remove` work on it. The keys are kept sorted. The values may be of any kind unless `'ValueType'` limits them. A map is a handle: assigning it to another variable gives the same map, and a change through either is seen by both.

# Syntax
M = containers.Map()
    Empty, text keys.
M = containers.Map(keys, values)
    From cells (or arrays) of keys and values.
M = containers.Map('KeyType', kt, 'ValueType', vt)
    Empty, of given types: `'char'`, `'double'`, ...
# Examples
## Capitals, and a shared handle
M = containers.Map({'Sweden', 'Norway'}, {'Stockholm', 'Oslo'});
M('Sweden')
M('Finland') = 'Helsinki';
M.Count
N = M;
N('Denmark') = 'Copenhagen';
M.Count
# See also
keys values dictionary

@ keys, values, isKey, remove
The keys and values of a map or a dictionary, whether it has a key, and keys removed.

For a `containers.Map`, `keys` gives the keys sorted as a cell row and `values` the values in that order (or those of some keys); `remove` takes keys out of the map itself. For a `dictionary`, keys and values come in the order they were put in, as columns, and `remove` gives a new dictionary without them. `isKey` answers for one key or several.

# Syntax
k = keys(M)
    The keys.
v = values(M)
    The values.
v = values(M, keySet)
    Those of some keys.
tf = isKey(M, key)
    Whether it has them.
remove(M, key)
    Keys taken out of a map.
d = remove(d, keys)
    A dictionary without them.
# Examples
## A map's keys sorted, a dictionary's in order
M = containers.Map({'b', 'a', 'c'}, {2, 1, 3});
keys(M)
values(M, {'c', 'a'})
isKey(M, {'a', 'z'})
remove(M, 'b');
keys(M)
d = dictionary(["b" "a"], [2 1]);
keys(d)'

containers.Map dictionary

@ deal
Inputs copied to outputs: one each, or one to all.

`[a, b] = deal(x, y)` is `a = x; b = y`; `[a, b] = deal(x)` gives both x. With a struct array or a cell array, `[s.field] = deal(v)` sets a field of every element. In an anonymous function, deal returns several outputs.

# Syntax
[a, b, c] = deal(x, y, z)
    One each.
[a, b, c] = deal(x)
    The same to all.
# Examples
## Swapping, filling, and a function of two outputs
[a, b] = deal(1, 2);
[a, b] = deal(b, a)
s = struct('v', {1, 2, 3});
[s.v] = deal(0);
[s.v]
minmax = @(x) deal(min(x), max(x));
[lo, hi] = minmax([4 9 2])

struct nargout

@ iscell, iscellstr, isstruct
Tests for a cell array, a cell array of character vectors, and a struct.

`iscellstr` is true only when every cell holds a character vector (an empty cell array counts).

# Syntax
tf = iscell(x)
    A cell array.
tf = iscellstr(x)
    Of character vectors.
tf = isstruct(x)
    A struct.
# Examples
## A few values tested
[iscell({1, 'a'}) iscellstr({1, 'a'}) iscellstr({'x', 'yz'}) iscellstr({})]
[isstruct(struct('a', 1)) isstruct({})]
