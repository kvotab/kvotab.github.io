@ missing
The missing value: it becomes NaN, a missing string, NaT or an undefined category where it is put.

One way to write "no value" for every kind of data: `[1 missing 3]` is `[1 NaN 3]`, `["a" missing]` a string array with a missing string, and assigned into a datetime or categorical array it becomes NaT or undefined. `ismissing` finds them all.

# Syntax
m = missing
    The missing value.
# Examples
## The same missing value in three kinds of array
x = [1 missing 3]
s = ["a" missing "c"]
d = datetime(2026, 11, 1:3);
d(2) = missing
ismissing(s)
# See also
ismissing fillmissing rmmissing

@ fillmissing
Missing entries filled: by a constant, from neighbours, by interpolation or by a moving statistic.

Missing entries are NaN, empty text, NaT and undefined categories. Methods: `'constant'` (a value), `'previous'`, `'next'`, `'nearest'`, `'linear'`, `'spline'`, `'pchip'`, `'makima'`, `'movmean'` and `'movmedian'` (with a window). `'EndValues'` says what happens at the ends (`'extrap'` unless given, `'nearest'`, `'none'`, ...) and `'MaxGap'` leaves longer gaps unfilled. A table is filled variable by variable.

# Syntax
F = fillmissing(A, 'constant', v)
    By a value.
F = fillmissing(A, method)
    From neighbours or by interpolation.
F = fillmissing(A, 'movmean', window)
    By a moving statistic.
F = fillmissing(..., 'EndValues', how, 'MaxGap', g)
    With options.
[F, TF] = fillmissing(...)
    With the entries filled.
# Examples
## A series with gaps, filled three ways
t = 1:10;
y = [1 2 NaN 4 5 NaN NaN 8 9 NaN];
F1 = fillmissing(y, 'previous')
F2 = fillmissing(y, 'linear')
F3 = fillmissing(y, 'linear', 'EndValues', 'none')
plot(t, y, 'o', t, F2, '.-'), legend('data', 'linear fill', 'Location', 'northwest')
# See also
rmmissing standardizeMissing ismissing

@ rmmissing
Missing entries removed, or the rows or columns that have them.

For a vector, the missing elements go; for a matrix, the rows with any missing element (the columns with `dim` 2), or only those with at least `'MinNumMissing'`; for a table, the rows with a missing value in its variables.

# Syntax
R = rmmissing(A)
    Without them.
R = rmmissing(A, dim)
    Columns instead (dim 2).
[R, TF] = rmmissing(..., 'MinNumMissing', n)
    Rows with at least n missing, and which were removed.
# Examples
## A vector and a matrix
rmmissing([1 NaN 3 NaN 5])
A = [1 2; NaN 4; 5 NaN; 7 8];
[R, TF] = rmmissing(A)
# See also
fillmissing ismissing

@ standardizeMissing
Values that stand for "missing" made the standard missing value.

Data often mark gaps with a code such as -99 or `'N/A'`; `standardizeMissing` makes them NaN (or empty text, NaT or undefined) so that the functions that know missing values treat them as such.

# Syntax
B = standardizeMissing(A, indicators)
    The indicators made missing.
B = standardizeMissing(T, indicators, 'DataVariables', vars)
    In a table's variables.
# Examples
## A code for no reading
y = [12.1 -99 13.4 -99 12.8];
B = standardizeMissing(y, -99)
mean(B, 'omitnan')

fillmissing ismissing

@ isoutlier
Which values are outliers.

By default a value more than 3 scaled median absolute deviations from the median, which outliers themselves hardly move; `'mean'` uses 3 standard deviations, `'quartiles'` 1.5 interquartile ranges beyond the quartiles, `'grubbs'` and `'gesd'` statistical tests, and `'movmedian'` and `'movmean'` a moving window for data that drift. `'ThresholdFactor'` changes the 3; the other outputs give the thresholds and the centre.

# Syntax
TF = isoutlier(A)
    By scaled median absolute deviation.
TF = isoutlier(A, method)
    By another method.
TF = isoutlier(A, 'movmedian', window)
    Within a moving window.
[TF, L, U, C] = isoutlier(..., 'ThresholdFactor', t)
    With the thresholds and centre.
# Examples
## Two outliers found
x = [2.1 2.3 1.9 2.2 9.5 2.0 2.4 -4 2.1];
[TF, L, U, C] = isoutlier(x)
find(TF)
## In drifting data, with a moving window
rng default
t = (1:100)';
y = t/10 + 0.3*randn(100, 1);
y([30 70]) = y([30 70]) + 4;
tf = isoutlier(y, 'movmedian', 15);
plot(t, y, '.', t(tf), y(tf), 'ro'), legend('data', 'outliers', 'Location', 'northwest')
# See also
filloutliers rmoutliers

@ filloutliers, rmoutliers
Outliers replaced, or removed.

`filloutliers` replaces the outliers that `isoutlier` finds (its methods and options, after the fill method): with the centre, clipped to the thresholds, from neighbours, by interpolation, or by a number. `rmoutliers` removes them; for a matrix, the rows that have one (or `'MinNumOutliers'` of them).

# Syntax
B = filloutliers(A, fillmethod)
    Replaced: `'center'`, `'clip'`, `'previous'`, `'next'`, `'nearest'`, `'linear'`, `'spline'`, `'pchip'`, `'makima'` or a number.
B = filloutliers(A, fillmethod, findmethod)
    Found by another method.
B = rmoutliers(A)
    Removed.
[B, TFrm] = rmoutliers(A, method)
    With which were removed.
# Examples
## The same outliers replaced and removed
x = [2.1 2.3 9.5 2.0 2.4 -4 2.2];
filloutliers(x, 'linear')
filloutliers(x, 'clip')
[B, TF] = rmoutliers(x)
# See also
isoutlier fillmissing

@ smoothdata
Noisy data smoothed.

A moving mean of a window chosen from the data by default; other methods are `'movmedian'`, `'gaussian'`, `'lowess'` and `'loess'` (local regression), `'rlowess'` and `'rloess'` (robust to outliers) and `'sgolay'` (Savitzky-Golay, `'Degree'` 2 unless given). The second output is the window used.

# Syntax
B = smoothdata(A)
    A moving mean.
B = smoothdata(A, method, window)
    Another method and window.
B = smoothdata(A, dim, method, window)
    Along a dimension.
[B, window] = smoothdata(...)
    With the window used.
# Examples
## Three smoothers on a noisy curve
rng default
x = linspace(0, 4*pi, 200)';
y = sin(x) + 0.3*randn(200, 1);
[B1, w] = smoothdata(y);
w
B2 = smoothdata(y, 'gaussian', 20);
B3 = smoothdata(y, 'sgolay', 25);
plot(x, y, '.', x, B1, x, B2, x, B3)
legend('data', 'movmean', 'gaussian', 'sgolay')

smooth movmean filter

@ findgroups, splitapply
Groups numbered, and a function applied to each group.

`findgroups` gives each element its group's number (groups in sorted order) and the group values; several grouping variables make groups of their combinations. `splitapply(func, X, G)` splits the data by group and applies the function to each part, one row of results per group: the split-apply-combine of summaries by category.

# Syntax
[G, ID] = findgroups(A)
    Group numbers and values.
[G, ID1, ID2] = findgroups(A1, A2)
    By combinations.
Y = splitapply(func, X, G)
    A result per group.
[Y1, Y2] = splitapply(func, X1, X2, G)
    Several outputs.
# Examples
## Means by group
site = ["N"; "S"; "N"; "E"; "S"; "N"];
depth = [12; 30; 14; 8; 26; 13];
[G, sites] = findgroups(site)
meanDepth = splitapply(@mean, depth, G)
