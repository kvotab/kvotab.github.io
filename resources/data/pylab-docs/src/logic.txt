@ eq, ne, lt, gt, le, ge
Comparisons element by element: ==, ~=, <, >, <= and >=.

Each compares matching elements and gives a logical array: true (1) where the comparison holds. A scalar is compared with every element, and a row with a column makes a matrix. For text, `==` compares character by character and needs the same length: use `strcmp` to compare whole texts. Floating-point results rarely compare equal exactly; compare with a tolerance.

# Syntax
tf = A == B
    Equal.
tf = A ~= B
    Not equal.
tf = A < B
    Less than (and `>`, `<=`, `>=`).
tf = eq(A, B)
    The same as `A == B`; `ne`, `lt`, `gt`, `le` and `ge` likewise.
# Examples
## Comparisons and their results
x = [1 5 3 8];
x > 3
x == 3
x(x >= 3)
## A tolerance for computed values
0.1*3 == 0.3
abs(0.1*3 - 0.3) < 1e-12
# See also
and isequal strcmp find

@ and, or, not
Logical AND, OR and NOT element by element: &, | and ~.

`A & B` is true where both are nonzero, `A | B` where either is, `~A` where `A` is zero. In an `if` or `while` condition, `&&` and `||` are the short-circuit forms: they evaluate the right side only when they need to, and work on scalars.

# Syntax
tf = A & B
    True where both are nonzero.
tf = A | B
    True where either is nonzero.
tf = ~A
    True where `A` is zero.
tf = and(A, B)
    The same as `A & B`; `or(A, B)` and `not(A)` likewise.
# Examples
## Combining conditions
x = 1:8;
x > 2 & x < 6
x < 2 | x > 6
~(x > 4)
## Values in a range
v = [0.3 1.2 -0.1 0.9];
inRange = v >= 0 & v <= 1
# See also
xor any all if

@ xor
Logical exclusive OR: true where exactly one of the two is nonzero.

# Syntax
tf = xor(A, B)
    True where `A` or `B` is nonzero, but not both.
# Examples
## The four cases
xor([0 0 1 1], [0 1 0 1])
# See also
and or not

@ isequaln
Like isequal, with NaN equal to NaN.

Compares whole arrays as `isequal` does (the same size and the same values), but treats `NaN` values in the same places as equal: useful to compare data with missing values.

# Syntax
tf = isequaln(A, B, ...)
    True when every argument equals the first, NaN equal to NaN.
# Examples
## Missing values in the same places
a = [1 NaN 3];
b = [1 NaN 3];
isequal(a, b)
isequaln(a, b)
# See also
isequal isnan

@ isnan, isinf, isfinite
Tests for NaN, for infinite values, and for finite values.

Element by element. `NaN` is not equal to itself, so `isnan` is the way to find it. `isfinite` is true for numbers that are neither `Inf`, `-Inf` nor `NaN`.

# Syntax
tf = isnan(A)
    True for NaN.
tf = isinf(A)
    True for Inf and -Inf.
tf = isfinite(A)
    True for every other number.
# Examples
## The three tests
x = [1 NaN Inf -Inf 0];
[isnan(x); isinf(x); isfinite(x)]
## Keeping the finite values
y = [4 0/0 7 1/0 2];
y(isfinite(y))
# See also
ismissing NaN Inf rmmissing

@ ismissing
True for missing elements: NaN, <missing> strings, blanks in a char array, empty text in a cell, NaT, undefined categories.

What counts as missing depends on the kind of data: `NaN` in numbers, `<missing>` in strings, `NaT` in datetimes, undefined values in categorical arrays, empty text in a cell array of text, and blanks in a character array. For a table, each variable is tested.

# Syntax
tf = ismissing(A)
    True where `A` is missing.
tf = ismissing(T)
    For each element of each variable of a table.
# Examples
## Numbers, strings and cells
ismissing([1 NaN 3])
ismissing(["a", missing, "c"])
ismissing({'x', '', 'z'})
## Counting what is missing in each column
A = [1 NaN; NaN NaN; 3 4];
sum(ismissing(A))
