@ gcf, gca, gco, groot, clf, cla
The current figure and axes, the root object, and clearing them.

Graphics commands work on the current figure and its current axes: `gcf` and `gca` give them, making them when there are none. `gco` gives the object last clicked. `groot` is the root of every graphics object; its properties hold defaults (`set(groot, 'DefaultLineLineWidth', 2)`) and the list of figures. `clf` clears the current figure of its axes and everything in them; `cla` clears the current axes of what is plotted in them, keeping the axes.

# Syntax
f = gcf
    The current figure.
ax = gca
    The current axes.
h = gco
    The object last clicked.
r = groot
    The root object.
clf
    The figure cleared.
cla
    The axes cleared.
# Examples
## What is current, and clearing it
plot(1:5)
ax = gca;
class(ax)
numel(ax.Children)
cla
numel(ax.Children)
f = gcf;
f == ax.Parent
clf
isvalid(ax)
r = groot;
class(r)
bar([3 1 2]), title('a new plot after clf')

@ findobj, findall, allchild, ancestor
Graphics objects found by their properties, the children of an object, and an object's figure or axes.

`findobj` searches the objects under a parent (the root unless given) for those whose properties match: a name and value, a pattern (`-regexp`), objects having a property (`-property`), joined by `-and` (the default), `-or`, `-xor` and turned round by `-not`; `-depth` limits how far down it goes. It leaves out objects whose HandleVisibility is off, which `findall` finds too. `allchild` gives every child, hidden ones included; `ancestor` the figure or axes an object is in.

# Syntax
h = findobj(parent, 'Name', value)
    By a property.
h = findobj(parent, 'Tag', 'a', '-or', 'Tag', 'b')
    Either.
h = findobj(parent, '-regexp', 'Tag', pattern)
    By a pattern.
h = findall(parent, 'Name', value)
    Hidden ones too.
h = allchild(parent)
    Every child.
p = ancestor(h, 'figure')
    The figure it is in.
# Examples
## Lines picked out by tag and colour
plot(1:3, 'Tag', 'raw'), hold on
plot(2:4, 'r', 'Tag', 'fit')
plot(3:5, 'Tag', 'fit2'), hold off
numel(findobj(gca, 'Type', 'line'))
h = findobj(gca, 'Tag', 'raw', '-or', 'Color', [1 0 0]);
{h.Tag}
h2 = findobj(gca, '-regexp', 'Tag', '^fit');
numel(h2)
ancestor(h2(1), 'axes') == gca
