# pylab.html: tests

pylab.html is a desktop for programs in the MATLAB language: a Command
Window, an Editor with breakpoints, the Workspace, the Current Folder, the
Command History and figure windows. What is typed or run is compiled to
Python by `resources/py/plab` and run on NumPy and SciPy in Pyodide, in a
module worker (`resources/js/pylab-worker.mjs`).

The function pages the Help panel shows (`doc plot`) are written in
`resources/data/pylab-docs/src/*.txt` and built by `pylab_docs.py`, which
runs every example in a fresh workspace and stores what it prints and the
figures it leaves beside it; test_docs.py runs them all again and fails when
a page no longer matches what PyLAB does. After changing a page, or what a
documented function prints or draws:

    python3 resources/tests/pylab/pylab_docs.py           (every page)
    python3 resources/tests/pylab/pylab_docs.py plots     (one source file)

test_gsa.py also needs node: it runs Kompartment's own sensitivity functions
(`kompartment/src/domain`) through `gsa-kompartment.mjs` on the same designs.

Some suites check against Python packages the page does not use, as
references only: test_graphs needs networkx, test_ml scikit-learn,
test_statsmore statsmodels and scikit-learn, test_wavelets PyWavelets
(it says so and stops when that is missing). test_shapes needs Shapely,
which polyshape uses in the page too, and test_imagemore scikit-image
(a reference only). NetCDF is checked by reading the
files back with SciPy and h5py on their own; the netCDF library itself is
not needed.

No MAT-file in the tests was written by MATLAB: they come from SciPy, from
h5py and from data elements written out in `matfixtures.py` (string arrays
too, in the layout the open-source mat-io reader documents).

The browser test drives headless Chrome over the DevTools protocol
(`cdp.py`, needs the `websockets` package); the EPS files it saves are
read through by `pscheck.py`, which runs their PostScript operators on an
operand stack (there is no PostScript interpreter to draw them with). Start a server on the
repository root and Chrome on the ports in `PYLAB_HTTP_PORT` and
`PYLAB_CDP_PORT` (defaults 8811 and 9311), then run it:

    python3 -m http.server 8811 --bind 127.0.0.1
    "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
      --headless=new --remote-debugging-port=9311 --no-first-run \
      --user-data-dir=/tmp/pylab-chrome --disable-gpu \
      --use-fake-device-for-media-stream --use-fake-ui-for-media-stream \
      --autoplay-policy=no-user-gesture-required about:blank
    python3 resources/tests/pylab/test-ui.py

With `PYLAB_SHOTS=<folder>` it saves screenshots. Pyodide, NumPy and SciPy
come from cdn.jsdelivr.net, so the browser test needs the network.
