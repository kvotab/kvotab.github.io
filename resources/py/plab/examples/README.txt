Examples for pylab. Open one in the Editor (double-click it in the
Current Folder) and press Run, or type its name in the Command Window
after `cd examples`.

  basics.m        variables, matrices, indexing, strings, cells and structs
  waves.m         line plots: several lines, a legend, labels and a grid
  surfaces.m      surf, contour and a colorbar in subplots
  lorenz.m        the Lorenz system solved with ode45, drawn in 3-D
  collatz.m       a function file: loops, conditions, a local function
  sections.m      code sections (%%) to run one at a time with Ctrl+Enter
  spiral.m        an animation with drawnow
  stats_demo.m    random numbers, a histogram and summary statistics
  wavelab.m       a small app: a plot with controls, menus, a toolbar and a timer
